# v5.1 · v4.7 RTL 기반 게이트 공유 자원 비교

기준은 세현 v4.7 최종 RTL이다. 2층 공유와 전층 공유는 같은 Verilog 패키지에서 GRU 소비 블록만 수정했다. FIFO, 상위 포트, 1층 직접 가중치 전달, 2층 가중치 전달 단축, ROM 및 클록 제약은 v4.7 원본을 사용한다.

- **2층 공유**는 2층 후보 상태 계산의 reset 입력을 같은 뉴런의 update 값으로 바꾼다. 1층과 2층은 sigmoid 인스턴스를 시간 공유하므로, reset sigmoid에서 2층 입력 경로만 제거한다.
- **전층 공유**는 1·2층에서 reset 결과 대신 update 결과를 사용한다. 3층은 한 sigmoid 인스턴스에서 reset과 update를 인접한 클록에 계산하던 구조다. 기존 reset 클록에 update를 계산하고, 12비트 결과를 레지스터에 보관해 기존 update 클록의 상태 갱신에도 사용한다.
- Vivado가 사용되지 않는 reset 연산과 계수 전달 논리를 합성 중 제거한다. 상위 RTL의 계수 인터페이스는 유지한다.

## 평가 범위

Vivado 2024.1, xczu7ev-ffvc1156-2-e, 15 ns 클록, ResGRU OOC 합성, AreaOptimized_high. 기준과 두 후보를 동일한 설정으로 합성했다. 이전 배선 후 값과 직접 비교하지 않는다. 이번 범위는 합성 자원이며, QAT·재학습·정확도 측정·배치배선은 수행하지 않았다.

## 합성 후 자원

각 셀은 LUT / FF다. SRL은 연산 블록 내부 LUT에 포함된다.

| 블록 | v4.7 기준 | 2층 공유 | 전층 공유 |
|---|---:|---:|---:|
| 상위 제어 | 0 / 568 | 0 / 568 | 0 / 568 |
| 입력 준비 | 679 / 577 | 649 / 529 | 589 / 433 |
| FIFO | 16 / 7,987 | 15 / 7,907 | 13 / 6,277 |
| 연산 블록 내부 제어·저장 등 | 3,676 / 9,970 | 3,194 / 10,065 | 3,119 / 8,150 |
| recurrent 곱셈 하위 모듈 | 3,783 / 0 | 3,815 / 0 | 2,363 / 0 |
| sigmoid | 1,025 / 0 | 1,074 / 0 | 655 / 0 |
| tanh | 1,063 / 0 | 1,169 / 0 | 982 / 0 |
| 기타 연산 하위 모듈 | 11,379 / 2 | 11,456 / 2 | 10,027 / 2 |
| **전체** | **21,621 / 19,104** | **21,372 / 19,071** | **17,748 / 15,430** |
| DSP / BRAM 타일 | 347 / 7.5 | 347 / 7.5 | 282 / 7.5 |

2층 공유는 LUT 249개(1.15%), FF 33개(0.17%)를 줄였다. 전층 공유는 LUT 3,873개(17.91%), FF 3,674개(19.23%), DSP 65개(18.73%)를 줄였다. 전층 공유에서는 recurrent 곱셈 하위 모듈 LUT 1,420개, FIFO와 연산 블록 내부 FF 총 3,530개가 줄었다.

## 재현

저장소 루트에서 각 범위별로 새 출력 디렉터리를 사용한다.

```powershell
python v5/scripts/prepare_v47_shared_rtl.py layer2 v5/prj_v47_layer2/rtl
vivado -mode batch -source v5/scripts/synth_v47_shared_rtl.tcl -tclargs v5/prj_v47_layer2/rtl
```

기준은 baseline, 전층 공유는 all을 전달한다. 기존 학습 및 v4.6 기반 구현 기록은 [이전 v5.1 실험](../../docs/shared_gate_experiments.md)에 있다.

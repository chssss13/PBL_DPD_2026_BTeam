# v5-1.4 · GRU 1·2·3층 입력 기반 게이트

v4.6 자체 재학습 가중치에서 출발했다. 세 층의 reset·update 게이트에서 `W_hr h_prev`와 `W_hz h_prev`를 제거했다. candidate 계산과 은닉 상태 갱신에는 이전 상태를 사용한다. 2·3층만 같은 방식으로 바꾼 v5-1.3을 배선 후 비교 기준으로 삼았다. [v5-1.3](../v5-1.3/README.md)

## 재학습과 정확도

v4.6 배포 가중치를 기존 비트폭으로 자체 재학습한 뒤, 그 가중치로 v5-1.4를 초기화했다. DPA 200 MHz 학습 데이터에서 기존 게이트의 활성화 전 값에 맞춰 새 입력 기반 게이트의 가중치와 bias를 최소제곱으로 초기 보정했다. 이후 세 GRU 층의 가중치와 bias 360개를 함께 학습했다. 입출력 FC, PReLU와 층간 residual 계수는 고정했다.

PyTorch 학습 중 가중치 14/4와 bias 15/3 양자화를 반영했다. DPD 출력에 고정된 PA 대리 모델을 적용하고, PA 출력과 목표 이득을 곱한 입력 I/Q 사이의 정규화된 평균 제곱 오차를 최소화했다. 학습은 AMD Radeon RX 7800 XT에서 DirectML로 실행했다.

Adam 학습률은 두 구간 모두 `0.00025`였다. 첫 20 epoch의 마지막 가중치를 불러와 Adam 상태를 초기화했고, 16 epoch를 추가로 돌렸다. 추가 구간에서 검증 NMSE가 가장 낮았던 14번째 epoch의 가중치를 채택했다. v5-1.4에서 실제로 실행한 학습은 36 epoch이며, 채택 가중치는 누적 34 epoch 시점이다. [채택 가중치](weights) · [1차 검증 이력](initial_validation.json) · [추가 검증 이력](validation.json)

고정소수점 C-sim 출력 7,680개 I/Q 쌍을 같은 PA 대리 모델에 넣어 평가했다. GRU 상태 초기화 간격은 2,560샘플이었다.

| 모델 | NMSE (dB) | EVM (dB) | ACPR 좌 / 우 (dBc) | 판정 |
|---|---:|---:|---:|---|
| v4.6 자체 재학습 | −45.393 | −49.320 | −53.462 / −50.247 | 통과 |
| v5-1.3 · 2·3층 | −43.522 | −46.455 | −51.382 / −48.692 | 통과 |
| 전층 · 1차 20 epoch | −43.245 | −46.567 | −51.652 / −48.171 | NMSE 미달 |
| 전층 · 0.000075 추가 학습 | −43.349 | −46.744 | −51.767 / −48.169 | NMSE 미달 |

기준은 NMSE ≤ −43.48 dB, ACPR 좌 ≤ −50.39 dBc, ACPR 우 ≤ −47.83 dBc다. [평가 원본](comparison.csv) · [추가 학습 검증 이력](validation.json)

## 배치·배선 결과

Vitis HLS와 Vivado 2024.1, FPGA `xczu7ev-ffvc1156-2-e`, 목표 주기 15 ns, Vivado 합성 지시어 `AreaOptimized_high`를 사용했다. 배선용 RTL에 v5-1.3의 반올림 선행, 순환 누산 뒤 레지스터, 단일 tanh DSP 지정과 FIFO·가중치 전달 최적화를 적용했다. 파라미터 FIFO는 466개에서 416개로 줄었고, 32개씩 제어를 공유하여 13개 그룹으로 구성했다.

| 지표 | v4.6 | v5-1.3 | v5-1.4 | v5-1.3 대비 |
|---|---:|---:|---:|---:|
| LUT | 21,660 | 18,803 | **17,682** | −1,121 (−6.0%) |
| FF | 19,171 | 15,648 | **14,474** | −1,174 (−7.5%) |
| DSP | 347 | 298 | **253** | −45 (−15.1%) |
| BRAM 타일 | 7.5 | 7.5 | 7.5 | 동일 |
| WNS (ns) | +0.138 | +0.237 | **+0.273** | +0.036 |
| HLS 샘플 루프 II | 2 | 2 | 2 | 동일 |

배선 후 setup·hold 위반은 0개였다. 가장 느린 setup 경로는 FEx 역제곱근 ROM에서 시작한다. [타이밍](timing_summary.rpt) · [자원](utilization.rpt) · [배선 상태](route_status.rpt)

## 검증 재현

초기 HLS RTL은 기존 가중치로 Verilog co-sim을 수행했고, 16회 호출의 1,024개 I/Q 쌍이 C-sim과 일치했다. 최종 재학습 가중치와 배선용 RTL을 사용한 시뮬레이션에서도 120회 호출의 7,680개 I/Q 쌍이 같은 가중치의 C-sim 결과와 비트 단위로 일치했다. Python과 Icarus Verilog가 설치된 환경에서 이 폴더에서 재현할 수 있다. [검증 결과](verification.txt)

```sh
python verify.py
```

`src`, `tb`, `csynth.tcl`은 HLS 합성 입력이며, 배치·배선에 사용한 Verilog와 ROM은 `rtl`에 있다.

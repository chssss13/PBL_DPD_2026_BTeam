# v5-1.6 · FIFO 쓰기 완료 제어 공유

부모는 [v5-1.5](../v5-1.5/README.md)다. 같은 FIFO 그룹 안에서 쓰기 완료 상태가 함께 바뀌는 채널들이 플래그를 하나씩 공유하도록 했다. 총 416개 채널의 개별 플래그를 그룹당 하나로 묶어 13개로 줄였다. FIFO 깊이는 1이다.

## 검증 결과

| 항목 | v5-1.5 | v5-1.6 | 변화 |
|---|---:|---:|---:|
| LUT | 16,905 | 16,594 | −311 |
| FF | 14,448 | 14,086 | −362 |
| DSP | 253 | 253 | 0 |
| BRAM 타일 | 7.5 | 7.5 | 0 |
| WNS | +0.301 ns | +0.116 ns | −0.185 ns |

Vivado 2024.1, `xczu7ev-ffvc1156-2-e`, `AreaOptimized_high`, 15 ns에서 setup·hold를 통과했다. RTL 시뮬레이션에서 고정 가중치 7,680개 I/Q 쌍과 쓰기·완료 시점이 부모와 일치했다. 가중치를 바꾼 연속 16회 호출과 그룹별 쓰기 대기도 검증했다. [자원](utilization.rpt) · [타이밍](timing_summary.rpt) · [배선 상태](route_status.rpt) · [RTL 검증](verification.txt)

v5-1.4 재학습 가중치를 사용했다. PA 지표는 같은 평가 벡터의 RTL 출력 일치를 근거로 부모의 NMSE −43.528 dB, EVM −46.886 dB, ACPR −52.043 / −48.250 dBc를 계승한다.

## RTL 구성

[v5-1.4 RTL](../v5-1.4/rtl/)에 [v5-1.5의 GRU 소비 블록](../v5-1.5/rtl/)을 적용한 후, 이 폴더의 [최상위 RTL](rtl/ResGRU.v)로 교체한다.

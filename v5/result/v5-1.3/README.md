# v5-1.3 · GRU 2·3층 입력 기반 게이트

v4.6 자체 재학습 가중치에서 시작해 2층과 3층의 reset·update 게이트에서 이전 은닉 상태 항을 제거하고 재학습했다. 후보 상태와 은닉 상태 갱신에는 이전 상태를 사용한다. 정확도는 고정소수점 C-sim 출력을 PA 모델로 평가했다.

| 구현 | NMSE (dB) | EVM (dB) | ACPR 좌 / 우 (dBc) | LUT | FF | DSP | BRAM 타일 | WNS (ns) |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| v5-1 · 3층 | −44.282 | −47.635 | −52.087 / −49.212 | 19,899 | 18,125 | 307 | 7.5 | +0.005 |
| v5-1.3 · 2·3층 | −43.522 | −46.455 | −51.382 / −48.692 | 18,803 | 15,648 | 298 | 7.5 | +0.237 |

15 ns 목표, xczu7ev-ffvc1156-2-e, Vivado 2024.1. 두 구현의 HLS 샘플 루프는 II=2다. v5-1은 추가 물리 최적화 후 수치다. v5-1.3은 입력 가중합과 bias를 먼저 반올림하고, 순환 누산과 bias 덧셈 뒤에 레지스터를 두었다. 배선에 사용한 RTL에서는 tanh 보간 곱셈기 하나에 DSP 사용을 지정했다. 마지막 두 변경의 효과는 합산해 측정했다.

## 검증 재현

Python과 Icarus Verilog를 PATH에 설정하고 이 폴더에서 다음 명령을 실행한다.

```sh
python verify.py
```

검사는 배선에 사용한 IP의 기능 RTL을 컴파일하고 64샘플씩 120회 연속 호출한다. 제공 입력 7,680개에 대해 C-sim과 RTL의 I/Q 고정소수점 출력 15,360개를 주소별로 비교한다. 상태 초기화 간격은 2,560샘플이다. 테스트벤치에 설정한 파라미터는 weights 폴더의 체크포인트를 양자화한 값이다.

src와 csynth.tcl은 HLS 합성용이다. FIFO와 가중치 전달 변경 및 단일 DSP 지정을 포함한 최종 회로는 rtl에 있다. 배선 후 측정값은 timing_summary.rpt와 utilization.rpt에서 확인할 수 있다.

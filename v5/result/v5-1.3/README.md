# v5-1.3 · GRU 2·3층 입력 기반 게이트

**이전 v5 채택본이며 부모 구현은 v4.6이다.** 3층만 변경한 v5-1은 성능 비교에 사용했다. [부모 구현](../../../v4/result/v4.6/README.md) · [현재 채택본 v5-1.4](../v5-1.4/README.md)

## 모델 변경과 가중치 학습 순서

1. v4.6 배포 가중치를 기존 구조 그대로 재학습한 체크포인트에서 시작했다.
2. GRU 2·3층의 reset·update 게이트에서 이전 은닉 상태에 곱하던 두 항을 제거했다. 두 게이트는 현재 층의 입력으로 계산한다. 후보 상태 계산과 은닉 상태 갱신에는 이전 상태를 계속 사용한다. 변경한 두 층을 함께 재학습해 선택한 18번째 epoch의 NMSE는 −43.409 dB로 기준(≤ −43.48 dB)에 미달했다.
3. **18번째 epoch의 가중치에서 학습률을 0.000075로 낮춰 한 번 더 재학습했다.** 추가 학습의 9번째 epoch를 선택했고, 고정소수점 C-sim 출력을 PA 모델로 평가한 NMSE는 −43.522 dB로 통과했다. [최종 가중치](weights) · [단계별 정확도](comparison.csv)

## 하드웨어 수정사항

- tanh 입력의 가중합과 bias를 먼저 반올림하고 reset이 곱해진 순환값을 더한다. 최종 범위 제한은 덧셈 뒤에 수행한다.
- 순환 누산값과 bias의 합을 레지스터에 보관한 뒤 reset 게이트를 곱한다.
- 최종 RTL에서 tanh 보간 곱셈기 한 개를 DSP에 매핑했다. 마지막 두 변경의 효과는 함께 배선해 측정했다.

## 검증 재현

Python과 Icarus Verilog를 PATH에 설정하고 이 폴더에서 다음 명령을 실행한다.

```sh
python verify.py
```

검사는 배선에 사용한 IP의 기능 RTL을 컴파일하고 64샘플씩 120회 연속 호출한다. 제공 입력 7,680개에 대해 C-sim과 RTL의 I/Q 고정소수점 출력 15,360개를 주소별로 비교한다. 상태 초기화 간격은 2,560샘플이다. 테스트벤치에 설정한 파라미터는 weights 폴더의 체크포인트를 양자화한 값이다.

src와 csynth.tcl은 HLS 합성용이다. FIFO와 가중치 전달 변경 및 단일 DSP 지정을 포함한 최종 회로는 rtl에 있다. 배선 후 측정값은 timing_summary.rpt와 utilization.rpt에서 확인할 수 있다.

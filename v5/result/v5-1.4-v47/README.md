# v5-1.4 + v4.7 · GRU 2층 가중치 지연 우회

[v5-1.4](../v5-1.4/README.md)에 [v4.7의 전달 방식](../../../v4/result/v4.7/README.md)을 적용했다. 2층 가중치 `W_ir`, `W_iz`, `W_in`, `W_hn` 각 25개를 처음 받아 둔 소비 블록 레지스터에서 곱셈 입력으로 연결해, 뒤로 전달하던 지연 레지스터 3단을 우회한다. [가중치 100개의 전달 경로](weight_paths.json)

## 학습과 출력 검증

v5-1.4의 가중치를 그대로 썼다. v4.6 자체 재학습 가중치에서 출발해 Adam 학습률 0.00025로 세 층을 학습했으며, 총 36 epoch 중 누적 34 epoch의 가중치를 선택했다. [학습 방법과 검증 이력](../v5-1.4/README.md#재학습과-정확도) · [사용한 가중치](../v5-1.4/weights)

RTL 시뮬레이션에서 고정 가중치로 I/Q 7,680샘플이 비트 단위로 일치했다. 2층 가중치 100개를 호출마다 바꾼 연속 16회 테스트에서도 기준 RTL과 출력값·주소·기록 시점·호출 완료 시점이 일치했다. 같은 고정 가중치와 평가 벡터의 PA 지표는 v5-1.4의 NMSE −43.528 dB, EVM −46.886 dB, ACPR 좌·우 −52.043 / −48.250 dBc를 사용한다. [RTL 검증 로그](verification.txt) · [기존 PA 평가](../v5-1.4/comparison.csv)

## 배치·배선 결과

Vivado 2024.1, `xczu7ev-ffvc1156-2-e`, 15 ns, `AreaOptimized_high` 조건이다. Setup·hold 위반과 배선 오류는 0개였다. 기존 HLS 샘플 루프의 II는 2이며, 이번 RTL 변경으로 샘플 처리 스케줄을 다시 합성하지 않았다.

# v5-1.7 · PReLU 곱셈기의 계수 입력 폭 축소

부모는 [v5-1.6](../v5-1.6/README.md)이다. PReLU 계수는 원래 부호 있는 14비트 값이며 앞단에서 32비트로 부호 확장된다. PReLU 곱셈기 5개가 계수의 하위 14비트를 부호 있는 값으로 읽게 수정했다. 곱의 출력은 32비트다.

## 검증 결과

| 항목 | v5-1.6 | v5-1.7 | 부모 대비 | v5-1.5 대비 |
|---|---:|---:|---:|---:|
| LUT | 16,594 | 16,426 | −168 | −479 |
| FF | 14,086 | 14,072 | −14 | −376 |
| DSP | 253 | 248 | −5 | −5 |
| BRAM 타일 | 7.5 | 7.5 | 0 | 0 |
| WNS | +0.116 ns | +0.235 ns | +0.119 ns | −0.066 ns |

Vivado 2024.1, `xczu7ev-ffvc1156-2-e`, `AreaOptimized_high`, 15 ns에서 setup·hold를 통과했다. RTL 시뮬레이션에서 7,680개 I/Q 쌍과 쓰기·수락·완료 시점이 부모와 일치했다. 가중치와 PReLU 계수를 바꾸고 쓰기 대기를 유도한 연속 16회 호출도 검증했다. [자원](utilization.rpt) · [타이밍](timing_summary.rpt) · [배선 상태](route_status.rpt) · [RTL 검증](verification.txt)

v5-1.4 재학습 가중치를 사용했다. PA 지표는 같은 평가 벡터의 RTL 출력 일치를 근거로 부모의 NMSE −43.528 dB, EVM −46.886 dB, ACPR −52.043 / −48.250 dBc를 계승한다.

# v5-5.4 · 1·2층 공유 곱셈기 10개를 고정 계수 연산으로 대체

채택본 [v5-5](../v5-5)에서 파생된 DSP 절감 후보이다. 부모 [v5-5.3](../v5-5.3)에 적용한 PReLU 고정과 3층 APoT 가중치 18개를 유지했다. 여기에 1·2층 후보 상태의 순환 가중치 `W_hn`을 추가로 고정해 DSP를 202개에서 192개로 줄였다.

## 무엇을 바꿨나

1층과 2층은 같은 행·열의 순환 곱셈기를 번갈아 사용한다. 선택한 10개 위치에서는 두 층의 가중치를 각각 최대 두 개의 부호 있는 2의 거듭제곱으로 표현했다. RTL은 각 층의 곱을 고정 시프트와 덧셈·뺄셈으로 계산하고 기존 스케줄에 맞춰 결과를 고른다. 추가로 고정한 가중치 20개 중 4개는 기존 값과 같고 16개는 값이 달라졌다. 이번 변경에는 추가 재학습이 없었다. 이 가중치를 바꾸려면 대응하는 RTL 상수도 함께 갱신해야 한다.

## 배치·배선 후 결과

Vivado 2024.1, ZU7EV(-2), 목표 주기 15 ns, AreaOptimized_high. HLS 합성을 다시 수행하지 않고 기존 샘플 루프 II=2 스케줄의 RTL을 수정했다.

| DSP | 202 | 192 | −10 |

| WNS | +0.234 ns | +0.252 ns | +0.018 ns |

## 정확도와 출력 검증

두 층 중 더 큰 가중치 표현 오차가 작은 위치부터 골랐다. 검증 데이터에서 0·1·5·10쌍을 비교하고 세 지표를 통과한 후보 중 가장 많은 10쌍을 선택한 다음, 그 후보를 테스트 데이터로 평가했다.

| 구분 | NMSE (dB) | 좌 ACPR (dBc) | 우 ACPR (dBc) |
|---|---:|---:|---:|
| 통과 기준 | ≤ −43.48 | ≤ −50.39 | ≤ −47.83 |
| 검증 데이터 · 10쌍 | −44.12 | −50.57 | −49.31 |
| 테스트 데이터 · 7,680샘플 | −43.89 | −51.12 | −48.99 |

120회 연속 호출에서 테스트 입력 7,680개 I/Q 쌍에 대한 RTL 출력 15,360워드가 같은 가중치의 C-sim 결과와 일치했다. Python과 Icarus Verilog가 설치된 환경에서 이 폴더의 `python verify.py`로 다시 확인할 수 있다.

# v5 재학습과 FPGA 자원 최적화

**현재 v5 채택본이자 추가 하드웨어 최적화의 기준은 v5-5다.** GRU 1·2층에는 v5-1의 입력 기반 reset·update 게이트를, 3층에는 v5-3의 bias-only 게이트를 적용했다. 배포된 원본 DPD 체크포인트에서 float로 재학습하고, 고정소수점 C-sim 검증으로 59 epoch 가중치를 선택했다. [v5-5의 비교표·RTL·가중치·검증 절차](result/v5-5/README.md)

v5-5는 NMSE −43.89 dB, ACPR 좌·우 −50.91 / −48.91 dBc로 정확도 기준을 통과했다. 배선 후 LUT 15,527개, FF 12,660개, DSP 228개, BRAM 7.5타일이며 15 ns에서 WNS는 +0.515 ns다. 샘플 루프는 II=2이고, 최종 RTL의 I/Q 7,680쌍은 같은 가중치를 사용한 C-sim 결과와 비트 단위로 일치했다.

**최신 DSP 절감 후보는 v5-5.4다.** 1·2층이 공유하던 순환 곱셈기 10개를 고정 계수 시프트·덧셈으로 바꿨다. v5-5 대비 DSP는 228개에서 192개로 줄고 LUT는 1,426개 늘었다. 목표 15 ns에서 WNS +0.252 ns, 샘플 루프 II=2이며 테스트 NMSE와 좌·우 ACPR 모두 기준을 통과했다. [v5-5.4 결과와 검증 자료](result/v5-5.4/README.md)

v5는 v4.6을 공통 하드웨어 기준으로 삼아 GRU의 연산 구조와 고정소수점 정밀도를 변경했다. v5-1~v5-4의 아래 비교값은 v4.6 배포 가중치에서 자체 재학습한 체크포인트를 시작점으로 사용한 실험에 해당한다. v5-5와 2층 혼합 후보는 배포된 원본 DPD 체크포인트에서 시작했다. [v4.6 구현 및 보고서](../v4/result/v4.6/README.md)

v5-1.5는 v5-1.4에 v4.7의 GRU 2층 가중치 전달 최적화를 적용했다. 15 ns 타이밍을 통과했고, v5-1.4 가중치를 그대로 사용하면서 배선 후 LUT를 777개 줄였다. [v4.7 원본](../v4/result/v4.7/README.md) · [v5-1.5 RTL과 검증](result/v5-1.5/README.md) · [v5-1.4 학습 방법](result/v5-1.4/README.md#재학습과-정확도)

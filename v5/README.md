# v5 재학습과 FPGA 자원 최적화

**현재 v5 채택본은 v5-1.4다.** v4.6 자체 재학습 가중치에서 출발해 GRU 1·2·3층의 reset·update 게이트에 입력 기반 계산을 적용하고 세 층을 함께 재학습했다. [현재 채택본의 RTL·가중치·검증 절차](result/v5-1.4/README.md)

채택본은 NMSE −43.528 dB, ACPR 좌·우 −52.043 / −48.250 dBc로 정확도 기준을 통과했다. 배선 후 LUT 17,682개, FF 14,474개, DSP 253개, BRAM 7.5타일이며 15 ns에서 WNS +0.273 ns를 확보했다. 샘플 루프는 II=2이고, 최종 RTL의 7,680개 I/Q 쌍이 같은 가중치를 사용한 C-sim 결과와 비트 단위로 일치했다.

v5는 v4.6을 공통 기준으로 삼아 GRU의 연산 구조와 고정소수점 정밀도를 변경했다. 각 후보의 출발점은 **v4.6 구조에서 자체 재학습으로 얻은 새 가중치와 bias**다. 이 체크포인트는 v4.6 배포 가중치에서 시작해 한 차례 학습한 결과이며, v5 후보는 각 변경을 반영해 이 체크포인트에서 다시 학습했다. 하드웨어 비교에는 v4.6의 기존 P&R 결과를 사용한다. [v4.6 구현 및 보고서](../v4/result/v4.6/README.md)

v5-1.5는 v5-1.4에 v4.7의 GRU 2층 가중치 전달 최적화를 적용했다. 15 ns 타이밍을 통과했고, v5-1.4 가중치를 그대로 사용하면서 배선 후 LUT를 777개 줄였다. [v4.7 원본](../v4/result/v4.7/README.md) · [v5-1.5 RTL과 검증](result/v5-1.5/README.md) · [v5-1.4 학습 방법](result/v5-1.4/README.md#재학습과-정확도)

## 정확도

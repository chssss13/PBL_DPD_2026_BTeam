# v5 재학습과 FPGA 자원 최적화

**현재 v5 채택본은 v5-1.3이다.** 부모 구현은 v4.6이며, 3층 단독 적용본 v5-1은 비교 기준으로 보존한다. [현재 채택본의 RTL·가중치·검증 절차](result/v5-1.3/README.md)

채택본은 NMSE −43.522 dB, ACPR 좌·우 −51.382 / −48.692 dBc로 정확도 기준을 통과했다. 배선 후 LUT 18,803개, FF 15,648개, DSP 298개, BRAM 7.5타일이며 15 ns에서 WNS +0.237 ns를 확보했다.

v5는 v4.6을 공통 기준으로 삼아 GRU의 연산 구조와 고정소수점 정밀도를 변경했다. 각 후보의 출발점은 **v4.6 구조에서 자체 재학습으로 얻은 새 가중치와 bias**다. 이 체크포인트는 v4.6 배포 가중치에서 시작해 한 차례 학습한 결과이며, v5 후보는 각 변경을 반영해 이 체크포인트에서 다시 학습했다. 하드웨어 비교에는 v4.6의 기존 P&R 결과를 사용한다. [v4.6 구현 및 보고서](../v4/result/v4.6/README.md)

v4.7의 GRU 2층 가중치 전달 최적화는 별도 구현으로 보관했다. [v4.7 구현과 검증 결과](../v4/result/v4.7/README.md)

| 계열 | 문서에 기록한 구현 | 결과 |
|---|---|---|
| [v5-1](result/v5-1/README.md) | GRU 3층의 입력 기반 reset·update 게이트 | 이전 채택본 |
| [v5-1.3](result/v5-1.3/README.md) | 2·3층 입력 기반 게이트, 반올림 선행과 순환 경로 분리 | 현재 채택본, 정확도·타이밍 통과, 최종 RTL 7,680샘플 일치 |
| [v5-2](result/v5-2/README.md) | GRU 3층의 reset 순환 가중치 대각화 | 정확도 통과, 타이밍 위반 |
| [v5-3](result/v5-3/README.md) | GRU 3층의 bias 기반 reset·update 게이트 | 정확도 미달, P&R 미실행 |
| [v5-4](result/v5-4/README.md) | 데이터·가중치 비트폭 축소 | 두 조합의 정확도 통과, 배선 후 타이밍 결과는 조합별로 다름 |

v5-1~v5-3 문서에는 적용한 아이디어의 출처를 적었다. v5-4는 v4.6의 데이터와 가중치 정밀도를 단계적으로 낮춰 본 실험이다.

## 정확도

DPA 200 MHz 데이터 7,680샘플의 고정소수점 C-sim 출력을 PA 모델로 평가했다. 상태 초기화 간격은 2,560샘플이다. 정확도 판정 기준은 NMSE ≤ −43.48 dB, 좌측 ACPR ≤ −50.39 dBc, 우측 ACPR ≤ −47.83 dBc다. EVM은 비교 지표로 사용했다.

| **v4.6 자체 재학습 기준** | −45.39 | −49.32 | −53.46 / −50.25 | 통과 |

# v5.1 입력 projection 곱셈기 공유

## 변경 목적과 범위

입력 projection은 FEx 특징 6개에서 출력 5개를 만들기 위해 샘플마다 30번 곱한다. II=2에서 15개의 곱셈기를 목표로 이 층만 별도 HLS 함수로 분리했다. 함수에 II=2와 곱셈 연산 할당 상한 15를 지정했다. 각 출력의 곱 변환과 누산 순서, bias를 더하는 시점은 원본과 동일하다. HLS 지시의 실제 적용 여부는 리포트로 확인한다.

최종 성과의 비교 기준은 v4.6이다. 공유 저장소의 v4.2 C++는 v4.6 RTL을 만들기 전 단계이므로, 이 후보는 v4.2 소스와의 C-sim 비교로 먼저 선별한다. 기존 v4.6의 FIFO 후처리와 1층 직접 전달을 포함한 비교는 검증된 동일 RTL 흐름이 필요하다.

## 실행과 검증

Vitis HLS 2024.1에서 저장소 루트 기준 `vitis_hls -f v5/projection_screen.tcl`을 실행한다. 생성 소스와 실행 폴더는 `v5/prj_projection_screen/`에 두며, 기존 실행이 있으면 중단한다. 보관본의 v4.1 테스트벤치와 golden 입력을 양쪽에 사용해, v4.2 원본과 후보의 7,680개 출력을 비교한 뒤 일치할 때 후보를 합성한다.

기기 `xczu7ev-ffvc1156-2-e`, 목표 주기 15 ns, HLS uncertainty 1 ns, `LOOP_T` 목표 II=2로 실행했다. C-sim에서 두 출력 파일이 일치했다.

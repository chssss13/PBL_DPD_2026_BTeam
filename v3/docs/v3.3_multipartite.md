# v3.3 — Multipartite sigmoid

채택된 v3.2를 기준으로 sigmoid 보간 곱셈을 부분 오프셋 표와 덧셈으로 대체한다. tanh와 기준 원본은 보존한다.

근거: [de Dinechin와 Tisserand, Multipartite Table Methods, IEEE TC, 2005](https://perso.citi-lab.fr/fdedinec/recherche/publis/2005-TC-Multipartite.pdf). 논문의 부분 오프셋 분해를 사용하며, 기울기 그룹의 최솟값을 사용하는 고정소수점 근사는 자체 적용이다.

최종 채택: 전체 7,680샘플 독립 참조/C 및 C/RTL 일치, LOOP_T II=2, 실제 주기 14.897 ns(WNS +0.103 ns, WHS +0.034 ns), 배선 오류·미배선 0이다. PA NMSE −45.119343 dB, ACPR −53.300679 / −50.388694 dBc로 공식 기준을 모두 통과했다.

실제 LUT 39,854 / FF 41,222 / DSP 355 / BRAM 0이다. 부모 v3.2 대비 LUT −931(−2.28%), FF −5(−0.01%), DSP·BRAM 동일로 자원 개선 조건을 만족했다. ACPR 우는 0.312121 dB 개선됐고 NMSE·ACPR 좌는 각각 0.004157/0.089555 dB 악화됐다. 모든 정확도 지표가 개선된 결과로 해석하지 않는다.

검증 순서: sigmoid 전체 32768 입력 및 전체 7680 샘플 C/독립 참조 비교 → 합성 II=2 → RTL 일치 → 배치배선 15 ns 및 자원 비교. 자원 1% 이상 감소와 다른 자원 증가 1% 이하, PA 기준을 모두 만족해야 채택한다. 미달 후보는 삭제한다.

결과: [전체 flow·실제 PPA·정확도·재현 방법](../results/v3.3/RESULTS.md). 원본 근거는 `results/v3.3/evidence/`, 소스·설정·fixture는 `experiments/v3.3/`에 보존한다.

## 원문에서 가져온 기법

Ercegovac, Muller, Tisserand, *Simple Seed Architectures for Reciprocal and Square Root Reciprocal*, Asilomar 2005, III절:
[저자 공개 원문](https://perso.ens-lyon.fr/jean-michel.muller/EMTAsilomar05.pdf).

정규화 입력 m∈[1,2)에서 선형식 `5/4 − m/4`에 작은 보정 표를 더해 역제곱근 seed를 구성합니다. 원문의 원리는 초기 저정밀 반복을 좋은 seed로 대신하는 것입니다.

## 현재 적용한 변경

- 기존 Taylor 초깃값과 NR 4회를 제거하고, 선형식＋64항 보정 표＋정규화 영역 NR 1회로 대체합니다.
- 보정 표는 전체 정규화 입력 영역의 오차로 구성합니다. 제공 I/Q 데이터로 계수를 학습하지 않습니다.
- 정규화 영역은 unsigned 16/1, 보정항은 Q17의 signed 14비트입니다.
- 홀수 지수의 역정규화에는 Q16의 46341(약 1/√2)을 사용합니다. 최종 inverse는 기존 signed 16/5로 반올림·포화합니다.
- amp2=0은 inverse=0으로 정의하여 0 나눗셈 없이 유한한 출력을 냅니다.
- 입력 정규화·역정규화, 고정소수점 형식과 0 처리는 논문을 현재 FEx에 적용하기 위한 별도 설계입니다. 논문의 FPGA 수치를 현재 회로에 그대로 적용하지 않습니다.

먼저 Python 정수 분석으로 후보를 확인했습니다. 보정 표의 범위는 −7791~−250으로 14비트 안에 있습니다. 양의 amp2 전체 코드에서 포화를 반영한 이상적 inverse와의 최대 차이는 최종 Q11 기준 1LSB입니다. C++에서는 전체 16,384개 amp2 코드의 inverse를 독립 Python 참조와 대조합니다.

## 자원 기대와 판정

NR 반복과 초깃값의 곱셈을 줄이는 것이 핵심입니다. 반면 정규화용 우선순위 검출·시프트·보정 표·역정규화 곱셈은 추가됩니다. 따라서 연산 수 감소를 FPGA LUT/DSP 감소로 확정하지 않습니다.

v3.1 대비 LUT/FF/DSP 중 하나가 최소 1% 감소하고 다른 자원이 1% 넘게 증가하지 않는 기존 자원 선별 기준을 적용합니다. 이번 후보는 정확도 개선만으로 채택하지 않습니다. 가능한 더 큰 감소를 목표로 하되 공식 조건을 완화하지 않습니다.

필수 조건은 **II=2, 구현 후 15ns, setup/hold·배선 오류 0, 독립 참조/C/RTL 검증, PA NMSE≤−43.48·ACPR 좌/우≤−50.39/−47.83**입니다.

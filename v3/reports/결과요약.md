# 최종 결과와 포함된 근거

기준: `v1_gru_accum_wide_z_unsigned12_state_nosat_csynth`, Vitis HLS/Vivado 2024.1, `xczu7ev-ffvc1156-2-e`, 15ns 클록.

| 항목 | 기존 최종 결과 | 포함한 파일 |
|---|---|---|
| C-sim | 7,680개, Python·부모 대비 Q12 불일치0 | [C-sim 비교](validation/csim_comparison.json) |
| Verilog RTL co-sim | 7,680개 PASS, 기존 C-sim 출력과 일치 | [co-sim 보고서](validation/rtl_cosim_20261105/ResGRU_cosim.rpt) · [출력 비교](validation/rtl_cosim_20261105/rtl_comparison.json) |
| HLS LOOP_T | II=2, Depth18 | [LOOP_T 보고서](hls/Loop_LOOP_T_proc_csynth.rpt) |
| HLS 추정 | 13.881ns, LUT222,370 / FF127,980 / DSP489 | [HLS top 보고서](hls/ResGRU_csynth.rpt) |
| P&R 타이밍 | WNS+0.093ns, TNS0, WHS+0.037ns, setup/hold 위반0 | [타이밍 요약](pnr/timing_summary.rpt) |
| P&R 자원 | LUT41,387 / FF41,088 / DSP362 / BRAM0 | [자원 보고서](pnr/utilization.rpt) |

`15−WNS`로 계산한 비교 주기는14.907ns다. 데이터 경로 지연14.888ns와는 클록 경로·불확실성·setup 항목의 반영 여부가 다르다.

기존 동일 벡터 평가의 PA 지표는 NMSE−44.97dB, ACPR 좌/우−53.35/−50.08dBc다. 최종 단계에서는 저장된 참조와 C-sim 출력의 Q12 일치를 확인했다. 이 폴더의 재현 검증은 제공 입력·참조 출력에 대한 비교이며 PA 신경망을 다시 실행하는 것은 아니다.

2026-11-05에 최종 소스를 별도 HLS 프로젝트로 재합성해 Verilog/XSim co-sim을 수행했다. RTL 출력 7,680개는 기존 최종 C-sim 출력과 완전히 일치했고 Python 참조와 Q12 불일치는 0이다. 재생성 RTL 65개는 주석·공백을 제외한 텍스트가 기존 최종 RTL과 같다. [RTL 대조](validation/rtl_cosim_20261105/rtl_identity_comparison.json) · [실행 조건](validation/rtl_cosim_20261105/experiment.json) · [로그](../logs/cosim.log). 테스트벤치는 Windows 파일 한도 설정만 추가했다. 이는 HLS 생성 RTL 기능 검증으로, 배치·배선 후 netlist 시뮬레이션은 아니다.

시스템 외부 I/O 통합 타이밍과 보드 실측은 미실시다. HLS II=2, C-sim·RTL co-sim 통과, P&R 내부 타이밍 통과는 각각의 검증 결과다.

[z 입력 범위 검사](validation/z_gate_range_audit.json)와 [상태 포화 범위 검사](validation/state_saturation_range_audit.json)는 구현 전 검토 기록을 그대로 포함했다. 내부의 `not started` 등은 당시의 상태이며 최종 완료 여부를 뜻하지 않는다. 원본 보고서의 실행 경로·날짜는 보존했다.

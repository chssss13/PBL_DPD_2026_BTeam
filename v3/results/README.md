## 저장 구조

```text
results/
  README.md                 결과 목록
  batch/SUMMARY.md          실행 중 후보를 포함한 진행표
  v3.n/
    RESULTS.md             사람이 읽는 통합 결과
    state.json             자동화 상태와 정밀 수치
    evidence/
      reference/           독립 참조 출력
      csim/                C 출력·참조 비교·PA 평가
      csynth/              HLS 합성 보고서
      cosim/               RTL 출력·비교·보고서
      impl/                배치배선 로그·자원·timing 보고서
```

소스·설정·테스트 fixture 원본은 `../experiments/<버전>/`에 한 벌만 둔다. 실행 중 후보는 flow별 작업 디렉터리를 사용하며 채택 후 위 구조로 자동 정리한다. 미달 후보는 소스·결과·상세 문서를 실제 삭제한다.

## 수치 해석

실제 자원과 timing은 Vivado 배치배선 보고서 값이다. HLS 추정치는 각 문서의 별도 표에 기록한다. 감소는 −, 증가는 +로 표시하고 부모 대비 단일 변경의 영향과 기존 v3 대비 누적 효과를 구분한다.

PA는 제공 모델을 사용한 C 출력 평가다. RTL은 동일 후보의 전체 C 출력과 일치함을 확인한다. 후보의 독립 참조와 일치한다는 사실이 기준 원본과 bit-exact임을 의미하지는 않는다. 처리율은 보고 주기에서 환산한 정상상태 값이며 보드 실측·호출 오버헤드·전력 개선을 포함하지 않는다.

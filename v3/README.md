# v3 — 3주차 FPGA 자원 사용량 감소

정확도와 HLS II=2, 배치·배선 후 15 ns 조건을 유지하면서 FPGA 자원 사용량을 줄이는 것이 목표다. sehyeon v1 계보의 v2 최종본에서 출발해 sigmoid 대칭성, 포화 회로 및 Vivado 합성 설정을 검토했다. 자원 감소 여부는 HLS 추정치와 별도로 **배치·배선 후 LUT·FF·DSP·BRAM**을 기준으로 판단한다.

**현재 최종 채택(2026-11-07):** [v3.3 코드·검증·재현 보관본](result/v3.3/README.md). 부모 출력과 C-sim 7,680개 Q12 일치, HLS II=2, IP 내부 15 ns 제약에서 **WNS +0.090 ns, setup/hold 위반 0개**다. P&R 자원은 **LUT 37,419 / FF 38,575 / DSP 362 / BRAM 0**으로, v2 최종 대비 **LUT 3,968개(9.59%)**, **FF 2,513개(6.12%)** 감소하고 DSP·BRAM은 동일하다.

## 기준 코드와 범위

- 작업 브랜치: `sehyeon`.
- 기준: [sehyeon v1 계보의 v2 최종 채택본](../v2/result/final/README.md). hyeonseo 기반 v2.1~v2.3에서 직접 이어진 구현은 아니다.
- 현재 소스는 [v3.3/src](result/v3.3/src/), 이전 채택 소스는 [v3.2/src](result/v3.2/src/)와 [v3.1/src](result/v3.1/src/)에 보관한다. 기본 `package/src/`를 현재 최종본으로 간주하지 않는다.
- `v3`는 3주차 실험 계열이다. 별도의 v3.0 채택본은 없으며, C01~C23 등의 후보 식별자와 v3.1·v3.2·v3.3 채택 버전명을 구분한다.
- csynth 이상 진행한 후보는 채택·기각·보류 여부와 관계없이 [전체 실험 기록](result/README.md)에 남긴다. [미채택 실험 요약](result/미채택_실험요약.md)에서는 변경 내용과 미채택 이유를 간단히 볼 수 있다.

| [v3.1](result/v3.1/README.md) | C23에 Vivado IP 합성 `AreaOptimized_high` 적용 | 동일 C++·HLS RTL 사용 | 2 | 14.940 / +0.060 ns |

## 정확도와 타이밍 기준

| 지표 | 기준 | 현재 v3.3 |
|---|---:|---|
| PA NMSE (dB) | ≤ −43.48 | 기존 평가 −44.97과 동일 벡터 Q12 출력 일치 |
| PA ACPR L / R (dBc) | ≤ −50.39 / −47.83 | 기존 평가 −53.35 / −50.08과 동일 벡터 Q12 출력 일치 |
| HLS LOOP_T II | 2 | 2 |
| 배선 후 비교 주기 (ns) | ≤ 15 | 14.910 |
| setup / hold 위반 | 0 | 0 / 0 |

v3.1·v3.2·v3.3의 RTL co-sim과 보드 실측은 미실시다. 제공 입력의 출력 일치는 모든 입력에 대한 동등성 증명이 아니다. v3.3의 비교 주기는 `15 − WNS`이며, 최악 데이터 경로 지연 14.793 ns와 구분한다. 검증 범위와 원본 보고서는 [v3.3 상세 결과](result/v3.3/README.md)를 따른다.

## 공통 실행 조건

Vitis HLS / Vivado 2024.1, FPGA `xczu7ev-ffvc1156-2-e`, 목표 15 ns, HLS uncertainty 1 ns, DSP full reg false, LOOP_T II=2 요청, 2,560샘플마다 상태 초기화. 채택본은 data `15,3`, weight `14,4`, sigmoid·tanh 256구간 보간, FEx Newton–Raphson 4회 및 inverse `16,6`을 유지한다.

v3.1·v3.2·v3.3의 Vivado IP 합성은 `AreaOptimized_high`를 사용한다. C23 기본 설정 결과를 따로 보존해 소스 변경과 합성 설정 변경을 구분했다. 미채택 후보에는 클럭·uncertainty·자료형 등을 바꾼 실험도 있으므로 후보별 조건을 확인한다. 이후 소스가 바뀌면 같은 설정의 자원·타이밍 이득을 다시 검증한다.

## 최종 하드웨어 사용량

아래 수치는 Vivado 배치·배선 후 결과다. HLS 추정 자원은 각 버전의 상세 보고서에 따로 기록했다.

| 자원 | v2 최종 기준 | C23 기본 설정 | v3.1 | v3.2 | 현재 v3.3 | v2 대비 변화 |
|---|---:|---:|---:|---:|---:|---:|
| LUT | 41,387 | 40,734 | 39,862 | 38,047 | **37,419** | **−3,968 (−9.59%)** |
| FF | 41,088 | 41,071 | 41,168 | 40,960 | **38,575** | **−2,513 (−6.12%)** |
| DSP | 362 | 362 | 362 | 362 | 362 | 0 |
| BRAM | 0 | 0 | 0 | 0 | 0 | 0 |

v3.2 대비 v3.3은 LUT 628개(1.65%), FF 2,385개(5.82%)를 줄였고 15 ns를 통과했다. WNS 여유는 약 0.066 ns 줄었다. 자원 종류별 증감을 구분하며 LUT 감소율을 FPGA 전체 자원 감소율로 표현하지 않는다.

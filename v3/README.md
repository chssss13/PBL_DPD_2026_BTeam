# v3 — 최종본 이후 실험 기록

2026-11-05부터 자원 사용을 중심으로 검토한 실험을 기록한다. **csynth까지 진행한 후보**는 결과가 좋거나 나쁘거나 같은 목록에 남긴다. 합성 완료 여부와 검증 범위를 밝히고, 채택·기각은 사용자의 판단이 정해진 뒤 기록한다.

출발점은 sehyeon v1 계보의 [v2 최종 채택본](../v2/result/final/README.md)이다. v2.3 및 다른 브랜치의 같은 버전 번호와 계보를 혼동하지 않는다. 이전 실험 전체를 v3 후보로 옮기는 것은 아니다.

목록의 C01, C02 등은 실험 식별자다. 정식 버전명이나 채택 순번을 뜻하지 않는다. 2026-11-06 사용자 결정으로 C23을 **v3.1**로 채택하고 V01/N1b의 Vivado IP 합성 `AreaOptimized_high`를 현재 구현 설정으로 사용한다. C++ 소스는 `package/results/final_sigmoid_symmetry_csynth/src/`, 채택 설정 P&R 보고서는 `package/results/c23_areaoptimized_high_synth/timing100/`에 있다. 기본 설정 P&R도 비교용으로 보존한다. v3.1 RTL co-sim과 보드 실측은 미실시다.

기록은 부모 후보, 변경 내용, C-sim·정확도 검증, HLS II·자원·추정 타이밍, 가능한 경우 P&R 타이밍·자원, 판단과 남은 확인을 구분한다. 두 개 이상을 동시에 바꿨으면 각각의 효과를 분리해서 판단할 수 있는지 명시한다. 이후 결과가 추가돼도 과거 수치와 기각 이유를 덮어쓰지 않는다.

2026-11-07 사용자 결정: P08을 **v3.2**로 채택한다. [v3.2 코드·결과·재현](result/v3.2/README.md). v3.1 및 이전 수치는 비교 기록으로 유지한다.

## GitHub 공유 범위

`v3`는 실험 계열이며 별도 채택 버전 v3.0을 뜻하지 않는다. v2 최종본에서 시작한 후보를 기록하고, 채택 버전은 v3.1과 v3.2로 구분한다. 현재 최종은 v3.2다.

후보 폴더에는 확인 근거인 소스·조건·로그·보고서를 보존했다. `prj/` 내부 DB·DCP 등 대용량 중간 생성물과 개인 계획·회고는 제외했다. 원본 로그 및 후보 실행 Tcl의 절대경로는 당시 환경의 기록이다. 다른 PC에서 실행할 때는 버전별 패키지의 상대경로 재현 스크립트를 사용한다.

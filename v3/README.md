## v3.1 — hidden state 식 재구성

검증된 v2.2에서 `(1-z)*n + z*h_prev`를 `n + z*(h_prev-n)`으로 바꾼 후보다.
처음에는 새 v2.5라는 이름으로 실행했으며, 사용자 요청에 따라 v3.1로 분류한다.
과거 별도 보존본 `repro_v2_5`와 관계없는 새 실험이다.

구현·이관 완료. **15ns 실패로 사용자 요청에 따라 폐기했다.**
[버전별 이력](docs/experiment_history.md), [v3.1 상세·실패 원인](docs/v3.1_hidden_state.md),
[최종 비교표](results/COMPARISON.md)를 참고한다. 원본 로그·보고서는 `results/v3.1`에 있다.

- 정확도·C/RTL 참조 비교 PASS, II2 유지.
- 실제 DSP:711→646, LUT:44990→46196, FF:47877→49538, BRAM_18K:52→56.
- 실제 주기:14.885→15.410ns, WNS −0.410ns로15ns 실패.
- data_t/weight_t는16비트 유지. 차분은17/4 임시 형식으로 소수부13비트를 보존한다.
- 처리율 판정에서 호출 오버헤드는 제외한다. 클록15ns에서 II2는33.333MSps다.
- 15ns 실제 타이밍·정확도·II·자원까지만 보고하며 추가 후보는 실행하지 않는다.

자동 재실행은 차단했다. 소스와 결과는 실패 이력으로 보존하며 추가 후보는 실행하지 않는다.

`prj_v3_1_original`은 완료 후 이동한 원본 빌드 증거다. 내부 경로와 실행 당시 이름
v2.5를 보존하므로 직접 재개하지 않는다. 현재 채택 기준은 v2.2다.

# v3 — FPGA 자원 사용량 감소

[v2.6 최종본](../v2/result/v2.6/README.md)에서 시작해 아래 변경을 순서대로 적용했다. 각 버전의 README에서 소스 diff와 검증 결과를 확인할 수 있다.

| 버전 | 채택한 변경 | LUT | FF | DSP | BRAM | 비교 주기 (ns) |
|---|---|---:|---:|---:|---:|---:|
| v2.6 최종 | 기준선 | 41,387 | 41,088 | 362 | 0 | 14.907 |
| [v3.1](result/v3.1/README.md) | sigmoid 대칭표와 면적 중심 합성 설정 | 39,862 | 41,168 | 362 | 0 | 14.940 |
| [v3.2](result/v3.2/README.md) | recurrent 곱 결과의 포화 제거 | 38,047 | 40,960 | 362 | 0 | 14.845 |
| [v3.3](result/v3.3/README.md) | r/z bias 사전 합산 | 37,419 | 38,575 | 362 | 0 | 14.910 |

자원은 배치·배선 결과이며 비교 주기는 `15 ns − WNS`다. 이후 채택한 기존 v3.4와 v3.5는 각각 [v4.0](../v4/result/v4.0/README.md), [v4.1](../v4/result/v4.1/README.md)에 있다.

# C23 P&R 재시도 01

원본 C23 IP 생성 중 Vivado EXCEPTION_ACCESS_VIOLATION으로 종료됐다. 배치·배선이 시작되지 않았으며 직접 원인은 미확정이다. 기존 로그와 실패 IP 폴더를 보존하고 동일한 15ns 조건으로 별도 복사본에서 재시도한다. csynth/RTL 재생성 없이 복사한 syn 및 Verilog/VHDL 산출물의 SHA256을 검증했다. 완료 시 최악 setup 100경로와 타이밍·자원 보고서를 추출한다.

## 결과 (2026-11-06)

P&R 및 setup 100경로 추출 완료. IP 내부 15ns 조건에서 WNS +0.149257ns, WHS +0.036848ns, setup/hold 위반 0, 미배선 0이다. 비교 주기 14.851ns(15−WNS), 최악 데이터 경로 14.831ns이다.

| P&R 자원 | v2 최종 | C23 | 변화 |
|---|---:|---:|---:|
| LUT | 41,387 | 40,734 | −653 (−1.58%) |
| FF | 41,088 | 41,071 | −17 |
| DSP | 362 | 362 | 0 |
| BRAM | 0 | 0 | 0 |
| WNS | +0.092955ns | +0.149257ns | +0.056302ns |

시그모이드 함수 전수 비교와 C-sim 출력 일치는 부모 C23에서 확인했다. 최종 후보의 RTL co-sim, 외부 I/O 통합 타이밍 및 보드 실측은 미실시이며 채택 여부는 미정이다.

2026-11-06 사용자 결정으로 C23을 **v3.1**로 채택한다. 위 채택 미정은 결과 확인 당시 상태다.

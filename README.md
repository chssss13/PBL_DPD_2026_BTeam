# PBL_DPD_2026_BTeam

GRU 기반 디지털 전치왜곡(DPD) 모델을 FPGA에 구현하고, 전력증폭기 출력의 정확도와 샘플 처리 간격(II), 배선 후 타이밍·자원을 비교하는 프로젝트다.

## 현재 채택본과 DSP 절감 후보

**채택본은 v5-5**, 최신 DSP 절감 후보는 **v5-5.4**다. 두 구현 모두 1·2층 게이트는 현재 입력에서 계산하고, 3층 게이트는 bias만 사용한다. v5-5.4는 v5-5.3에서 1·2층이 공유하던 곱셈기 10개를 층별 고정 계수의 시프트·덧셈으로 바꿨다. 이때 고정한 가중치를 교체하려면 RTL에도 반영해야 한다. [v5 전체 비교](v5/README.md) · [혼합 모델의 수식과 구현 이력](v5/result/v5-5/README.md)

|---|---:|---:|---:|---:|---:|---:|---:|
| [v5-5 · 채택본](v5/result/v5-5/README.md) | −43.89 | −50.91 / −48.91 | 15,527 | 12,660 | 228 | 7.5 | +0.515 |

다섯 구현 모두 테스트 7,680샘플에서 정확도 기준을 통과했다. 자원과 WNS는 ZU7EV(-2), 목표 15 ns에서의 배치·배선 결과이며 샘플 루프는 II=2다. v5-5.1에서 DSP 8개를 줄이면서 LUT가 1,822개 늘었고, v5-5.2에서는 DSP 220개를 유지하면서 LUT를 937개 줄였다. v5-5.4는 직전 v5-5.3보다 DSP 10개와 FF 697개를 덜 쓰고 LUT 512개를 더 쓴다. [PYNQ-Z2 대상 별도 실험](v5/pynq-z2-feasibility.md)

## 이전 구현

v4 계열은 **[v4.0 기준선](v4/result/v4.0/README.md)**(기존 v3.4)에서 출력 FC, FEx, FIFO 및 가중치 전달을 순서대로 개선해 **[v4.7](v4/result/v4.7/README.md)**까지 검증했다. [v4.0~v4.7 변경과 결과 비교](v4/README.md).

v5-1~v5-4는 v4.6 자체 재학습 가중치에서 출발했고, v5-5 혼합 모델은 배포된 원본 DPD 체크포인트에서 재학습했다. 전 층 bias-only 게이트에 v4.7의 2층 가중치 우회를 적용한 별도 실험은 [적용 전 v5-3.1](v5/result/v5-3.1/README.md)과 [적용 후 v5-3.2](v5/result/v5-3.2/README.md)에서 비교할 수 있다. 두 후보 모두 15 ns 타이밍을 통과했고 PA 정확도 기준에는 미달했다.

기존 v4.0~v4.6 계열은 [미사용 보관본](v4_unused/README.md)으로 전환했다. 새 v4와는 별도 계열이다.

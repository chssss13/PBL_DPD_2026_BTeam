## 래퍼 포함 배치·배선 결과 (15ns)

| 항목 | 4_1 | 4_2 | 4_3 |
|---|---:|---:|---:|
| LUT | 22,893 | 22,955 | 22,221 |
| FF | 20,804 | 20,507 | 19,666 |
| DSP | 355 | 355 | 355 |
| BRAM | 0 | 0 | 0 |
| WNS (ns) | +0.059 | +0.088 | +0.031 |
| WHS (ns) | +0.029 | +0.037 | +0.027 |
| 배선 오류 | 0 | 0 | 0 |

4_2와 4_3은 외부 인터페이스가 일치하는 input_weight_channel HLS IP 패키지에 각 후보 RTL 68개를 교체하여 bd_0_wrapper 방식으로 구현했다. 4_1과 HLS 메타데이터가 동일하다고 검증한 것은 아니다.

4_1은 기존 7,680샘플 검증 결과를 보유한다. 4_2와 4_3은 A→B 파라미터 전환 128샘플에서 4_1과 출력 일치 및 미정의 출력 없음을 확인했다. 전체 정확도, 임의 stall/reset, 보드 동작은 미검증이다. II=2는 기존 HLS 스케줄 기준이며 변경된 RTL의 모든 입력 조건에 대해 보장된 것은 아니다.

각 `rtl/`은 시뮬레이션에 사용한 Verilog 68개이며 `rtl_sha256.json`으로 확인할 수 있습니다. `hls_reference/`는 V3.8 HLS 소스 참조입니다. RTL에서 수행한 변경은 C++ 재합성만으로 재현되지 않습니다. 전체 테스트벤치와 벡터는 이 폴더에 포함되지 않습니다.

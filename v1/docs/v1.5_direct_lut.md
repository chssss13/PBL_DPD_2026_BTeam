# v1.5: 직접 조회 활성화 LUT

측정일: 2026-10-16. 입력·데이터 <16,3>, 가중치 <16,4>, 주요 누산기 <32,12>, 출력층 누산 <16,3>. reset 간격 2,560샘플, 전체 7,680샘플. FEx는 후보 B의 중간값 양자화와 역수 <16,8>을 유지하며 sqrt·역수 내부 double은 남아 있다. 재학습·golden 변경 없음.

## 변경 내용

v1.5은 조회 경로를 단순하게 하려고 음수 구간도 표에 포함했다.
`<16,3>`의 입력 범위 `[-4,4)`를 1/512 폭의 4,096개 구간으로 나누고,
각 구간 중앙에서 계산한 함수 값을 저장한다.
표의 크기는 커지지만 절댓값 계산과 음수 출력 복원을 없앨 수 있다.

```text
16비트 입력 → 상위 12비트 [15:4] 추출 → 4,096개 표 중 하나 조회 → 16비트 출력
```

`<16,3>`은 소수부가 13비트이므로 하위 4비트를 인덱스에서 제외하면
입력 16단계, 즉 `16 / 8192 = 1/512` 폭을 하나의 구간으로 묶는다.
음수 비트 패턴에 맞게 표를 배치했으므로 실행 중 부호 변환도 필요 없다.
이 방식이 `ACT_LUT=2`이며, 활성화 함수 경계와 지연 제약도 함께 지정했다.
지연을 0으로 요청한 pragma가 있더라도 최종 지연은 합성 보고서로 확인해야 한다.

C-sim 정확도는 NMSE -43.67 dB, ACPR -51.82/-48.38 dBc로 통과했지만
전체 시간 루프 II는 여전히 5였다. 따라서 조회 방식을 바꾸는 것만으로는 충분하지 않았다.
합성 로그에는 상태 갱신 연산을 DSP의 3클록 지연으로 배치하는 동작도 나타났다.

## 재현 설정

Vitis HLS 2024.1 Command Prompt에서 v1 폴더 기준. 아래 설정 후 `vitis_hls -f scripts/run_resgru.tcl` 실행.

```bat
set STEPS=csim csynth
set NT=7680
set ACT_LUT=2
set DIRECT_LUT_SHIFT=4
set FEX_INTERNAL_FIXED=1
set FEX_INV_I=8
set HLS_PROJECT=prj_review_v1_5
set DSP_FULL_REG=true
set CLOCK_UNCERTAINTY_NS=4.05
set TARGET_II=
set HLS_OUTPUT=
```

기존 프로젝트를 덮어쓰지 않도록 재현용 프로젝트명을 사용했다. 기본 출력 results/hls_out.txt는 재실행 시 덮어써진다.

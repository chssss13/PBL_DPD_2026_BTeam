# PPA 이력표

우리 팀의 v0 재현부터 E09 구현까지 실제 수정·검증 순서에 맞춰 작성한 이력입니다.
모사 탐색과 실제 HW 측정을 구분합니다. 미측정은 `—`로 표시하며 0이나 통과를 의미하지 않습니다.

- 기능검증: `compare_out.py` 결과 (참조 대비 NMSE, PASS/FAIL)
- 정확도: `eval_pa.py` 결과 (PA 통과 NMSE / ACPR L / ACPR R)
- 처리율 = Fmax / II (MSps). Fmax는 구현 후 값 (`export_impl.rpt`의 Post-Route)
- **0행은 E08의 기능 복구 후보를 E09에서 구현한 동일 회로**입니다. 정확도·II·RTL 검증은 통과했지만 **15 ns 타이밍은 미달**입니다. 타이밍까지 만족한 완성본과 구분합니다.
- 향후 개선률은 0행 대비로 계산합니다. v0 대비 값은 참고 비교로만 표시합니다.
- 측정 환경: Windows PC `DESKTOP-TCLI4QB`, Vitis HLS/Vivado 2024.1, `xczu7ev-ffvc1156-2-e`, 목표 15 ns. CPU/물리 메모리는 이번 기록에서 확인하지 않았습니다.
- v0와 E09는 같은 PC에서 측정했지만 HLS clock uncertainty는 각각 4.05 ns(27%), 1 ns로 다릅니다. 동일 합성 제약 비교는 아닙니다.
- 전체 정확도 평가 입력은 7,680샘플, PA는 2,560샘플 × 3구간. 모든 PA 수치는 NMSE(dB) / ACPR L·R(dBc) 순서입니다.
- 전력은 측정하지 않았습니다. 아래 이력은 면적·성능·정확도이며 전력 개선을 주장하지 않습니다.

## 0행 판정 및 다음 변경의 기준

- 정확도: NMSE 여유 약 0.19 dB, ACPR L 약 1.43 dB / R 약 0.55 dB. 세 조건 모두 통과.
- 기능: 7,680샘플 전체 C/RTL co-sim PASS. RTL/Python 비교도 PASS.
- 성능: II=2 통과. Post-Route 24.054 ns로 15 ns 목표 실패. 추정 주파수 약 41.57 MHz.
- 자원: 대상 칩에 배치·배선 완료, unrouted nets=0. v0 팀 실측 대비 LUT 약 +43.3%, FF 약 +0.4%, DSP 약 +9.7%로 자원 절감은 아직 달성하지 못함.
- 전력: 미측정. 전력 수치는 추정해 채우지 않음.
- 다음 변경은 0행 대비 자원·속도 변화와 정확도 유지 여부를 기록하되, 우선 정확도와 II=2를 유지하며 타이밍 경로를 줄이는 작업이 필요.

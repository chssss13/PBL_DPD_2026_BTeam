# v1.6: II=2 스케줄 조정 및 RTL 검증

측정일: 2026-10-16. 입력·데이터 <16,3>, 가중치 <16,4>, 주요 누산기 <32,12>, 출력층 누산 <16,3>. reset 간격 2,560샘플, 전체 7,680샘플. FEx는 후보 B의 중간값 양자화와 역수 <16,8>을 유지하며 sqrt·역수 내부 double은 남아 있다. 재학습·golden 변경 없음.

## 변경 내용

v1.6은 v1.5의 함수 값·비트 배분·가중치·초기화 조건을 그대로 사용한다.
새로운 수학 근사를 추가한 것이 아니라 HLS의 스케줄 설정을 다음과 같이 변경했다.

| 설정 | 변경 내용 | 목적과 주의점 |
|---|---|---|
| `DSP_FULL_REG=false` | DSP의 전체 레지스터화 기본 동작 해제 | DSP 연산을 자동으로 긴 레지스터 단계에 배치하는 동작을 줄일 여지를 줌. 모든 DSP가 조합회로가 된다는 뜻은 아님 |
| `CLOCK_UNCERTAINTY_NS=1.0` | 기본 여유 4.05 ns를 1 ns로 축소 | 15 ns 클록에서 HLS가 조합 경로에 쓸 수 있는 시간을 약 10.95 ns에서 14 ns로 늘림. 실제 물리 타이밍 여유는 줄어듦 |
| `TARGET_II=2` | 시간 루프 파이프라인에 II=2 요청 | 요청만으로 달성이 보장되지 않으므로 최종 보고서의 achieved II를 확인 |

이 변경들을 함께 적용한 결과 실제 합성 보고서에서 `LOOP_T II=2`를 얻었다.
각 설정이 단독으로 얼마만큼 기여했는지까지 분리한 실험은 아니므로,
특정 옵션 하나만으로 II=2가 됐다고 해석하면 안 된다.
진짜 은닉 상태 의존성을 무시하도록 지시하거나 서로 다른 시퀀스를 끼워 넣지는 않았다.

이후 전체 7,680샘플을 RTL co-sim으로 실행해 C와 일치하는지 확인했고 PASS했다.
RTL 출력의 PA 정확도도 v1.5과 같은 NMSE -43.67 dB, ACPR -51.82/-48.38 dBc였다.
즉, 계산 결과를 유지하면서 합성 스케줄을 바꿔 II를 5에서 2로 줄인 후보다.
다만 클록 여유를 줄였고 자원도 많이 사용하므로 실제 배치·배선 후 타이밍과 자원 수용 여부는 별도 검증 대상이다.

## RTL 검증과 실제 구현

- 전체 7,680샘플/120블록 C/RTL co-sim PASS.
- RTL/Python 비교도 −196.93 dB, PASS. 위 PA 정확도는 실제 RTL 출력의 평가 결과다.
- co-sim top latency 166 cycles, 호출 interval 134 cycles.
  이 값은 HLS 스케줄의 top latency/interval 및 샘플 II와 구분한다.
- Windows TV 파일 생성 오류는 TB의 `_setmaxstdio(2048)` 적용 후 재시도해 해결했다.
- 같은 회로의 실제 구현은 [v1.7 구현·PPA](v1.7_implementation.md)에서 수행했다.
  구현 LUT 66,859 / FF 49,754 / DSP 711 / BRAM 0, Post-Route 24.054 ns로 15 ns 타이밍은 실패했다.
- HLS II=2와 RTL 정확도를 만족해도 목표 클록에서 물리 구현 가능하다는 뜻은 아니다.

## 재현 설정

Vitis HLS 2024.1 Command Prompt에서 v1 폴더 기준. 아래 설정 후 `vitis_hls -f scripts/run_resgru.tcl` 실행.

```bat
set STEPS=csim csynth
set NT=7680
set ACT_LUT=2
set DIRECT_LUT_SHIFT=4
set FEX_INTERNAL_FIXED=1
set FEX_INV_I=8
set HLS_PROJECT=prj_review_v1_6
set DSP_FULL_REG=false
set CLOCK_UNCERTAINTY_NS=1.0
set TARGET_II=2
set HLS_OUTPUT=
```

기존 프로젝트를 덮어쓰지 않도록 재현용 프로젝트명을 사용했다. 기본 출력 results/hls_out.txt는 재실행 시 덮어써진다.
기존 성공 후보 프로젝트 재사용은 `scripts/run_ii2_candidate.cmd` 및 `scripts/cosim_existing.tcl`을 따른다.

# v4 — 초기 v1에서 분기한 정확도·자원 재최적화

> **2026-11-15 계열 채택본: v4.5.** 팀 비교 기준은 [v3.5](reference/v3.5/README.md). 현재 v4는 15ns 타이밍 미달이므로 v3.5를 팀 최종본에서 대체했다는 의미가 아니다.

## 계보와 버전 기준

v4.0은 사용자가 v1.0으로 부른 초기 정확도 복구본(`c3e35cd / result/04_lut4096/source`)이다. 이 소스의 P&R은 미실시이며 자원·타이밍은 공란으로 둔다. v1 최종 `result/07`의 결과와 혼동하지 않는다. v3.5에서 직접 분기한 계열이 아니다.

v4.1 이후는 P&R 완료 후 다음 실험의 부모로 선택한 이력을 순서대로 번호화했다. 실행 폴더명·후보 이름과 채택 버전명을 구분한다. A처럼 HLS까지만 본 후보와 현재 r/z 분리 후보는 버전 번호를 부여하지 않는다.

## 구현 조건과 해석

Vitis HLS/Vivado2024.1, xczu7ev-ffvc1156-2-e, 15ns, HLS uncertainty1ns, DSP full reg false, 목표 II2. v4.1~v4.5는 Vivado 기본 구현 흐름이며 AreaOptimized_high는 추가하지 않았다. 비교 기준 v3.5에는 AreaOptimized_high가 적용되어 있어 소스 외 설정 차이가 있다. HLS uncertainty와 최종 Vivado 보고서의 clock uncertainty는 구분한다.

v4.0~v4.4 data16,3·weight16,4, v4.5 data16,3·weight14,4. v4.1~v4.5 Q13 보간. v3.5는 data15,3·weight14,4이며 출력층 누산21,6이 포함된다. v4 출력층에 그 변경을 가져온 것으로 간주하지 않는다.

v4.2 및 v4.4는 결합 변경이다. 자원 감소는 변경 묶음의 측정 결과이며 각 변경의 개별 효과나 세부 회로 원인을 분리해 측정하지 않았다. v4.3은 실패한 첫 IP 생성 로그와 동일 RTL 재시도 결과를 구분하고 성공한 retry01의 보고서를 보존했다.

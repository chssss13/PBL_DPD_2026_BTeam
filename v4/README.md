2026-11-15 버전 체계를 정리했다. **기준선 v4.0은 기존 v3.4, 현재 채택본 v4.1은 기존 v3.5**다. 번호만 재정리했으며 소스·실험 조건·결과는 동일하다.

| 주요 변경 | v3.3에서 inverse_t 16/6 → 16/5 | v4.0에서 출력층 누산 21/6 |
| Python PA NMSE (dB) | -44.96 | -45.03 |

| P&R LUT | 37,331 | 37,415 |

PA는 동일 7,680샘플, 상태 리셋 2,560샘플 조건이다. golden NMSE는 -45.52dB이며 차이는 반올림된 수치로 계산했다. 각 C-sim은 해당 Python 참조와 Q12 불일치 0이다. RTL co-sim 및 보드 실측을 완료했다는 뜻은 아니다.

Vitis HLS/Vivado 2024.1, xczu7ev-ffvc1156-2-e, 목표 클럭 15ns, uncertainty 1ns, II=2, Vivado AreaOptimized_high 조건이다. 자원 표는 HLS 추정치가 아닌 P&R 결과다. 재현 명령과 원본 보고서는 각 패키지에 포함했다.

## 발표용 계열과 후속 실험

**v4.1은 출력 FC 수정 계열, v4.2는 FEx 수정 계열**로 구분한다. v4.2는 비교를 위한 계열명이며 개별 후보를 채택했다는 뜻은 아니다. v4.1에 FIFO를 적용한 실험도 아래 비교에 포함한다. FIFO 변경은 깊이 2→1과 32개 채널 단위 제어 공유를 함께 적용했다.

| 후보 | FEx | Output FC | FIFO 변경 | Vivado 합성 옵션 | 상태 |
|---|---|---|---|---|---|
| v4.1 | NR 4회 | 21/6 | 없음 | AreaOptimized_high | 채택본 |
| v4.1 FIFO | NR 4회 | 21/6 | 적용 | AreaOptimized_high | P&R 완료, 타이밍 미달 |
| v4.2 다항식·FC 15/3 | 다항식 | 기존 15/3 | 없음 | — | Python 정확도만 평가 |
| v4.2 다항식·FC 21/6 | 다항식 | 21/6 | 적용 전·후 비교 | 기본 / AreaOptimized_high | P&R 완료, 옵션별 결과 상이 |
| v4.2 전체 ROM·FC 21/6 | 다항식 결과를 BRAM에서 조회 | 21/6 | 적용 전·후 비교 | 기본 / AreaOptimized_high | P&R 완료 |

세부 정확도, 자원, 옵션 및 소스는 [v4.2 계열 비교](result/v4.2/README.md)를 참조한다. 전체 ROM은 다항식 자체가 아니라 입력별 최종 역제곱근 값을 저장한다. FIFO는 후처리 RTL 변경으로 적용했으며 HLS 원본 RTL만으로 재현되지 않는다.

## 기존 v4 계열 보관

초기 v1에서 다시 출발했던 기존 v4.0~v4.6은 모두 **미사용 구현**으로 분류하고 [v4_unused](../v4_unused/README.md)에 보존했다. 기존 번호는 과거 기록 식별용이며 이 문서의 새 v4 번호와 혼동하지 않는다. 해당 소스·보고서는 삭제하지 않았다.

# v4 — 정확도 개선과 FIFO 자원 절감

v4.0은 기존 v3.4를 옮긴 기준선이다. v4.1에서는 출력 FC의 누산 정밀도를 높였고, v4.2에서는 FEx를 변경했다. v4.3부터는 FIFO와 양쪽 블록에서 파라미터를 전달할 때 드는 FF를 줄였다.

## v4.7 이후 추가 구현

v4.7에서 출발해 적용한 변경을 시간순으로 정리했다. **비교 후보**는 별도로 구현해 같은 조건에서 비교한 실험이다.

- **비교 후보 — GRU 리셋 게이트 곱셈기 공유.** 층별로 따로 두었던 `r` 후단 곱셈기를 서로 다른 클럭 차례에서 번갈아 쓰도록 HLS 코드를 변경했다.
- **GRU 상태 갱신 DSP 통합.** 세 층의 상태 갱신 15곳에서 `z × (h_prev − n)`과 `+ n`을 같은 DSP 블록에서 계산하도록 RTL을 변경했다.
- **DSP 상한 설정.** 상태 갱신 통합본에 Vivado 합성 옵션 `-max_dsp 220`을 적용했다. 어떤 곱셈을 DSP와 LUT에 배정할지는 Vivado가 정한다.
- **FEx 압축 ROM.** 역제곱근과 함께 진폭·진폭 세제곱을 구간별 기준값과 차이로 저장해 조회하고, 진폭을 구하던 곱셈 두 단계를 대체했다.
- **리셋 게이트 곱셈 폭 축소.** 세 층의 `r` 후단 곱셈 15곳에서 부호 있는 15비트로 전달하던 게이트 값을 소수부 12비트의 부호 없는 값으로 표현했다.
- **비교 후보 — HLS에서 LUT 곱셈 지정.** GRU의 `r`·`z` 입력 행렬곱, 출력 FC, 잔차 연결과 `r` 후단의 일부 곱셈에 `fabric`을 지정해 HLS를 다시 실행했다. 같은 RTL에 v4.7 후처리와 상태 갱신 통합을 적용한 뒤 DSP 상한 유무를 비교했다.
- **PReLU 계수 폭 축소.** FEx 압축 ROM과 리셋 게이트 폭 축소를 적용한 DSP 220개 계열에서, PReLU 곱셈기 5개가 32비트로 부호 확장된 계수를 14비트 폭으로 읽도록 바꿨다.
- **배치·배선 전략 변경.** PReLU 계수 폭 축소본의 합성 결과를 재사용하고 Vivado 구현 전략에 `Performance_NetDelay_high`를 적용했다.
- **공유 곱셈기의 가중치 입력 폭 축소.** LUT로 구현된 공유 곱셈기 중 signed 14비트 가중치만 받는 66곳에서 가중치 입력을 29비트에서 14비트로 줄였다. 곱의 결과 폭은 29비트다.
- **FIFO 쓰기 완료 플래그 공유.** 채널별 쓰기 완료 플래그 566개를 같이 움직이는 18개 FIFO 그룹별로 하나씩 통합했다.

## 정확도

Python PA 평가에 동일 입력 7,680샘플과 상태 초기화 간격 2,560샘플을 사용했다. golden은 부동소수점 참조 모델이다.

| 지표 | Golden | v4.0 | v4.1 | v4.2 | v4.3~v4.7¹ |
|---|---:|---:|---:|---:|---:|
| NMSE (dB) | −45.52 | −44.96 | −45.03 | −45.19 | −45.19 |
| Golden 대비 NMSE 차이 (dB) | 0 | +0.56 | +0.49 | +0.33 | +0.33 |
| EVM (dB) | −49.42 | −48.75 | −48.78 | −48.90 | −48.90 |
| ACPR 좌 (dBc) | −53.59 | −53.61 | −53.51 | −53.43 | −53.43 |
| ACPR 우 (dBc) | −50.43 | −50.31 | −50.38 | −50.25 | −50.25 |

¹ v4.3~v4.6은 7,680샘플 RTL co-sim을 통과했고, 각 단계의 출력 비교에서 같은 벡터의 참조 또는 부모 출력과 일치해 v4.2의 PA 수치를 이어 썼다. v4.6은 호출마다 1층 가중치를 바꾸는 1,024샘플 추가 테스트도 통과했다. v4.7은 같은 7,680샘플에서 v4.6과 RTL 출력값·출력 시점이 일치했다. 검증 범위는 해당 벡터와 호출 조건이다.

## 블록별 FF 변화

v4.2에서 **FIFO 저장부와 제어부는 19,448 FF로 전체 41,015 FF의 47.4%**를 차지했다. 입력 준비 블록은 FIFO에 보낼 값을 준비하는 별도 계층이다. 소비·연산 블록에는 수신 파라미터 저장, 상태 및 파이프라인 FF도 포함된다. 표는 P&R 계층 보고서 기준이며, FIFO 제어부에는 공유 제어 계층의 FF도 포함한다. [계층별 집계 CSV](result/ff_breakdown.csv).

### v4.2 → v4.3 · 제어 공유

| FF 사용처 | v4.2 | v4.3 | 변화량 |
|---|---:|---:|---:|
| 입력 준비 블록 | 8,529 | 8,529 | 0 |
| FIFO 데이터 저장부 | 16,052 | 15,902 | −150 (−0.9%) |
| FIFO 제어부 | 3,396 | 130 | −3,266 (−96.2%) |
| 소비·연산 블록 | 12,470 | 12,202 | −268 (−2.1%) |
| 상위 동기화·기타 | 568 | 568 | 0 |

FIFO 제어부에서 3,266 FF(96.2%)가 줄었다. 두 결과 모두 기본 옵션이다.

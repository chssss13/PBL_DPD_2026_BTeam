# v4.5 — 입력 준비 블록의 출력 보관 레지스터 제거

[v4.4](../v4.4/README.md)에서 FIFO에 보낼 값을 따로 보관하던 출력 레지스터 묶음 566개를 입력 준비 블록에서 제거했다. FIFO가 받을 때까지 준비 블록이 출력 상태에 머물도록 제어를 바꿨다. 그동안 출력에 쓰이는 입력과 내부 값은 안정적으로 유지돼야 한다.

| P&R 항목 | v4.4 기본 | v4.4 면적 | v4.5 면적 |
|---|---:|---:|---:|
| 입력 준비 블록 FF | 8,529 | 8,529 | 577 |
| FIFO 저장부 + 제어부 FF | 7,987 | 7,987 | 7,987 |
| 전체 FF | 29,556 | 29,372 | 21,539 |
| 전체 LUT | 26,991 | 25,663 | 21,398 |
| WNS (ns) | +0.101307 | +0.107510 | +0.059697 |

입력 준비 블록에서 **7,952 FF(93.2%)**가 줄었다. 발표 기준 전체 LUT **5,593개 감소**에는 합성 옵션 차이도 포함된다. 같은 면적 옵션에서는 전체 LUT가 **4,265개**, 전체 FF가 **7,833개** 줄었다. 레지스터를 없애면서 해당 출력값을 선택하고 유지하던 논리도 단순해졌을 것으로 해석한다. [블록별 FF 비교](../../README.md#블록별-ff-변화).

Verilog/XSim co-sim에서 제공된 7,680샘플을 통과했다. 부모 출력과 Q12 불일치는 0개였다. 호출 지연은 144클록, 호출 간격은 134클록이다. 이 검증은 제공된 벡터와 호출 조건에 해당한다.

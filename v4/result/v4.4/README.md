# v4.4 — FIFO 깊이 2→1

[v4.3](../v4.3/README.md)의 제어 공유를 유지하면서 채널마다 대기할 수 있는 값을 두 개에서 한 개로 줄였다. FIFO가 가득 차면 생산 블록은 공간이 생길 때까지 다음 값의 전달을 기다린다. 비교한 v4.4 RTL은 v4.2의 HLS 생성 RTL에 깊이 1과 제어 공유를 함께 적용해 만들었다.

v4.3과 같은 기본 합성 옵션에서 FIFO 저장부는 **15,902→7,951 FF(−50.0%)**, FIFO 제어부는 **130→36 FF**였다. 전체 LUT는 **31,934→26,991**, 전체 FF는 **37,331→29,556**으로 줄었다. 저장 위치가 하나여서 두 위치 중 하나를 선택하는 논리와 주소 관리가 단순해진다. [블록별 FF 비교](../../README.md#블록별-ff-변화).

| 합성 옵션 | LUT | FF | WNS (ns) | 비교 주기 (ns) |
|---|---:|---:|---:|---:|
| 기본 | 26,991 | 29,556 | +0.101307 | 14.898693 |
| AreaOptimized_high | 25,663 | 29,372 | +0.107510 | 14.892490 |

기본 옵션은 v4.3과 같은 조건으로 비교한 결과다. 면적 옵션은 [v4.5](../v4.5/README.md)와 같은 옵션으로 비교할 때 사용한다. 두 경우 모두 DSP 347개와 BRAM 7.5타일을 썼다.

변환 RTL의 7,680샘플 Verilog/XSim co-sim을 통과했고, Python 참조와 Q12 불일치는 0개였다. 호출 지연은 144클록, 호출 간격은 134클록이다.

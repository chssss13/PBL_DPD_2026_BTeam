# v4.7-1 · GRU 3층 가중치 전달 한 단계 단축

부모는 채택본 v4.7이다. 2층 단축을 유지하고 3층 가중치 150개가 마지막 전달 레지스터 대신 바로 앞 단계에서 값을 읽도록 바꿨다. 배선 후 FF가 늘어 자원 절감 기준에서는 v4.7을 유지한다.

| 배선 후 지표 | v4.7 | v4.7-1 | 변화 |
|---|---:|---:|---:|
| LUT | 20,069 | 19,971 | −98 |
| 그중 지연용 LUT | 1,760 | 1,313 | −447 |
| FF | 19,200 | 20,671 | +1,471 |
| 사용 CLB | 5,102 | 5,386 | +284 |
| DSP | 347 | 347 | 0 |
| BRAM 타일 | 7.5 | 7.5 | 0 |
| 15 ns 기준 타이밍 여유 | +0.051 ns | +0.072 ns | +0.021 ns |

동일 면적 최적화 옵션으로 비교했다. 기존 가중치 시험과 호출마다 2·3층 가중치를 바꾼 시험에서 각각 7,680샘플을 120회 연속 호출로 처리했다. 두 시험 모두 부모 대비 I/Q 출력 15,360개의 값·기록 시점·주소와 호출 완료 시점이 일치했다.

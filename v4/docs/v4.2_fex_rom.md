# v4.2 — FEx BRAM ROM 조회

## 목적과 변경

비교 기준은 v4.1이다. Newton–Raphson 4회 대신 16,384개 입력 코드의 역제곱근 값을 조회한다. 저장값은 구간별 1차식으로 미리 계산했다. 출력 FC와 깊이 2 FIFO는 유지했다.

## 배치·배선과 정확도

| 항목 | 결과 |
|---|---|
| LUT / FF / DSP / BRAM 타일 | 36,810 / 41,015 / 347 / 7.5 |
| 비교 주기 | 14.759 ns |
| 15 ns setup | 통과 |

PA NMSE −45.03→−45.19 dB, DSP −15. BRAM 7.5타일을 사용하고 FF는 2,512개 늘었다. 두 버전의 합성 옵션이 다르다.

## 기능 검증과 재현 범위

동일 7,680샘플 Python PA 평가와 P&R 보고서 확인. FEx 소스와 ROM 표, PA 평가, 보고서를 보관한다. 독립 재현 패키지는 제공하지 않는다.

구현 및 검증 근거는 [원본 결과와 파일 목록](../result/v4.2/README.md), 공통 조건과 블록별 수치는 [v4 개요](../README.md)를 참고한다.

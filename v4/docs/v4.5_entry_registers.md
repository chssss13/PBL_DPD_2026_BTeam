# v4.5 — 입력 준비 블록의 출력 레지스터 제거

## 목적과 변경

비교 기준은 v4.4이다. FIFO 직전 출력 보관 레지스터 묶음 566개를 제거하고, FIFO가 받을 수 있을 때까지 생산 블록을 출력 상태에 머물게 했다. 대기 중 전달값은 안정적으로 유지해야 한다.

## 배치·배선과 정확도

| 항목 | 결과 |
|---|---|
| LUT / FF / DSP / BRAM 타일 | 21,398 / 21,539 / 347 / 7.5 |
| 비교 주기 | 14.940 ns |
| 15 ns setup | 통과 |

동일 면적 옵션에서 LUT −4,265와 FF −7,833. 입력 준비 블록 FF 8,529→577, FIFO 저장·제어 FF 7,987 유지.

## 기능 검증과 재현 범위

7,680샘플 RTL co-sim PASS, 부모 Q12 불일치 0, 호출 지연 144클록·간격 134클록. 보고서와 출력 대조 기록을 보관한다. 최종 후처리 자동 재생성 절차는 공유본에 포함되어 있지 않다.

구현 및 검증 근거는 [원본 결과와 파일 목록](../result/v4.5/README.md), 공통 조건과 블록별 수치는 [v4 개요](../README.md)를 참고한다.

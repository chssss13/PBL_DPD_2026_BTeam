# v4.3 — FIFO 채널 제어 공유

## 목적과 변경

비교 기준은 v4.2이다. 읽기·쓰기가 함께 일어나는 566개 채널을 최대 32개씩 묶어 공유 제어기 18개를 사용한다. 저장 공간은 채널별로 두고 깊이 2를 유지했다.

## 배치·배선과 정확도

| 항목 | 결과 |
|---|---|
| LUT / FF / DSP / BRAM 타일 | 31,934 / 37,331 / 347 / 7.5 |
| 비교 주기 | 14.680 ns |
| 15 ns setup | 통과 |

같은 기본 합성 옵션에서 FIFO 제어 FF 3,396→130, 전체 FF 41,015→37,331.

## 기능 검증과 재현 범위

Verilog/XSim 7,680샘플 통과, 부모와 출력 파일 일치, 호출 지연 144클록·간격 134클록. 특정 v4.2 생성 RTL을 전제로 하는 후처리 단계다.

구현 및 검증 근거는 [원본 결과와 파일 목록](../result/v4.3/README.md), 공통 조건과 블록별 수치는 [v4 개요](../README.md)를 참고한다.

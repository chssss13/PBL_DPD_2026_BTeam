# v4.0 — FEx 역제곱근 정밀도 조정

## 목적과 변경

비교 기준은 v3.3이다. 16비트 역제곱근 형식의 정수부를 6→5비트, 소수부를 10→11비트로 바꿨다. Taylor 초깃값과 Newton–Raphson 4회는 유지했다.

Python PA 평가와 7,680샘플 C-sim Q12 비교. RTL co-sim 미실시. C++ 소스, 테스트벤치, 입력, 재현 스크립트와 P&R 보고서가 있다.

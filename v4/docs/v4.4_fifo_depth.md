# v4.4 — FIFO 깊이 축소

## 목적과 변경

비교 기준은 v4.3이다. 공유 제어를 유지하고 저장 깊이를 2→1로 바꿨다. 한 칸이 차면 생산 단계를 대기시켜 아직 소비되지 않은 값을 보호한다.

## 배치·배선과 정확도

| 항목 | 결과 |
|---|---|
| LUT / FF / DSP / BRAM 타일 | 26,991 / 29,556 / 347 / 7.5 |
| 비교 주기 | 14.899 ns |
| 15 ns setup | 통과 |

기본 옵션에서 FIFO 저장 FF 15,902→7,951, 전체 FF 37,331→29,556. 면적 옵션은 LUT 25,663·FF 29,372·14.892 ns.

## 기능 검증과 재현 범위

7,680샘플 RTL co-sim PASS, Python 참조 Q12 불일치 0, 호출 지연 144클록·간격 134클록. 기본·면적 옵션 보고서와 특정 v4.2 생성 RTL용 변환 스크립트가 있다.

구현 및 검증 근거는 [원본 결과와 파일 목록](../result/v4.4/README.md), 공통 조건과 블록별 수치는 [v4 개요](../README.md)를 참고한다.

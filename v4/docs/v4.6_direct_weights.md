# v4.6 — GRU 1층 가중치 직접 전달

## 목적과 변경

비교 기준은 v4.5이다. 1층 입력 가중치 W_ir, W_iz, W_in 각 25개를 소비 블록의 전달 레지스터 대신 FIFO에서 곱셈기로 공급한다.

## 배치·배선과 정확도

| 항목 | 결과 |
|---|---|
| LUT / FF / DSP / BRAM 타일 | 21,660 / 19,171 / 347 / 7.5 |
| 비교 주기 | 14.862 ns |
| 15 ns setup | 통과 |

동일 면적 옵션에서 LUT +262, FF −2,368, WNS +0.059697→+0.138466 ns. DSP와 BRAM 유지.

## 기능 검증과 재현 범위

7,680샘플 RTL co-sim 및 부모 Q12 일치. 호출별 1층 가중치 변경 1,024샘플 통과. 호출 지연 144클록·간격 134클록. 75개 연결 변경 기록과 검증·P&R 보고서를 보관한다. 전체 자동 재생성 절차는 공유본에 포함되어 있지 않다.

구현 및 검증 근거는 [원본 결과와 파일 목록](../result/v4.6/README.md), 공통 조건과 블록별 수치는 [v4 개요](../README.md)를 참고한다.

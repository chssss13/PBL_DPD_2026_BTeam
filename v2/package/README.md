# v2 계산 코드 — v2.2 상태

v1.7 시점의 코드를 기준으로 GRU 연산 구조와 활성화 함수를 수정한 코드다. 출처와 결과는 [v2 개요](../README.md), 검증 당시 스냅샷과 재현 명령은 [v2.1](../result/v2.1/README.md) / [v2.2](../result/v2.2/README.md)에 있다.

- `src/`: 합성 대상 C++ / 헤더. 현재 활성화 후보는 `ACT_LUT=3`의 512구간 정수 선형 보간이다. 실행 시 define을 명시해야 하며 기본 옵션만으로 같은 후보가 선택된다고 가정하지 않는다.
- `tb/`: golden 입력·가중치 파일을 읽는 테스트벤치. 파일 내용은 합성 ROM 초기값이 아니라 시뮬레이션 입력으로 전달한다.
- `tools/`: Python 참조·평가·표 생성 도구.
- `golden/`, `opendpd_min/`: 제공된 검증 데이터·가중치·PA 모델과 평가 의존 코드. 원본 라이선스는 각 경로에 보존한다.
- `docs/`: 가져온 원본 참고 문서. 그 안의 v1 측정값은 원본 브랜치의 기록이며 이번 v2 결과와 구분한다.

기본 `scripts/run_resgru.tcl`은 프로젝트를 초기화한다. 기록된 버전을 재현할 때는 보고서에 제공한 전용 `source/reproduce.tcl`을 사용한다.

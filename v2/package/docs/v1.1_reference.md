# v1.1: golden에 가까운 초기 reference 확보

기존 v1.1(Python 탐색)과 v1.2(C 구현·검증)를 하나의 flow로 통합했다.
입력·가중치 16비트 제약을 유지하면서 golden에 가까운 후보를 찾고, 같은 계산을 C-sim으로 검증한다.
누산기 32비트와 활성화·FEx 내부 double을 사용한 정확도 기준점이며 II·구현 타이밍까지 만족한 버전은 아니다.
설계 흐름은 v1.1~v1.7로 재번호화했다. 후보 B의 합성은 v1.3에 포함하고, v1.7은 구현·PPA 평가 단계로 별도 유지한다. 과거 v1.2/E02는 현재 v1.1의 C 검증 단계를 뜻한다.

## 1. Python 자료형 탐색

측정일: 2026-10-16. 제공된 학습 가중치(seed 4574)를 유지하고 재학습하지 않음.
Python 탐색 단계에서는 HLS 소스를 수정하지 않았고, 선택 후보를 다음 C 검증 단계에서 반영했다. golden 데이터는 전체 과정에서 수정하지 않음.

### 조건

- 제공 `hw_ref.py`의 `run_fxp` 사용, 데이터와 가중치 모두 총 16비트.
- 활성화 exact, FEx exact, 은닉 상태 초기화 간격 2560.
- 입력 7680샘플 전체. PA 모델과 `eval_pa.py`는 배포본 그대로.
- 정수부 I에는 부호 포함. 반올림 AP_RND, 포화 AP_SAT 모사.
- NMSE <= -43.48, ACPR L <= -50.39, R <= -47.83을 모두 만족하면 통과.
- 정확한 활성화/FEx를 가정한 모사 결과이며, 아직 C-sim/RTL/II/자원 검증 결과가 아님.
- 특히 FEx 내부 sqrt/나눗셈은 고정소수점 회로로 구현한 것이 아니며 결과를 data_t로 양자화함.
- 출력 선형층 누산은 기존 참조 코드대로 data_t를 사용하므로, accum_t 변경은 모든 누산기에 적용되는 것은 아님.

### 해석과 다음 단계

- 기존 자료형만 남겨도 NMSE -41.88/R -44.78로 실패하므로, 활성화/상태 제어만 고쳐서는 충분하지 않음.

- 가중치 16,3은 범위 [-4,4)로 일부 원본 가중치를 담지 못하지만, 이 데이터에서 목표는 통과함. 포화가 없다는 뜻은 아님.

## 2. C 구현 및 C-sim 검증

2026-10-16, Vitis HLS 2024.1 Windows, 7680샘플 전체 C-sim 완료.

### 변경

- data_t = ap_fixed<16,3>, weight_t = ap_fixed<16,4>, accum_t = ap_fixed<32,12>.
- GRU sigmoid/tanh는 double 수학 함수로 계산한 후 data_t로 양자화.
- FEx는 double sqrt/나눗셈을 사용하고 각 출력에서 data_t로 양자화.
- ResGRU에 bool reset 인자 추가. 블록 첫 샘플에서 reset이 참인 경우만 상태 초기화.
- Tcl에서 RESET_ARG를 항상 정의해 기존 TB가 2560샘플 구간 시작을 전달하도록 설정.
- v0 package와 golden은 수정하지 않음.

이 버전은 Python에서 통과한 계산의 C-sim 재현용이다. double 내부 연산을 포함하므로
전체 연산이 16비트인 하드웨어라고 해석하면 안 된다. 합성/RTL/II/자원/타이밍은 아직 검증하지 않음.
기존 wrapper.cpp는 빌드 대상이 아니며, 변경된 reset 인터페이스 대응은 별도 필요.

### 결과

- CSim done with 0 errors, 7680샘플, csim_design 약 2분 15초.
- C와 Python 비교: NMSE -196.88 dB, PASS (기준 <= -60 dB).
- 최대 파일상 오차 5e-11. 텍스트 출력 소수 자릿수 차이가 있어 저장 파일의 완전 일치는 아님.
- C-sim PA 평가: NMSE -45.48 dB, EVM -49.34 dB, ACPR L/R -53.33/-50.37 dBc.
- Python PA 평가도 표시 정밀도에서 동일. 필수 정확도 세 기준 모두 통과.

### 재현 (Vitis HLS 2024.1 Command Prompt, v1 폴더)

```bat
set STEPS=csim
set NT=7680
set FEX_INTERNAL_FIXED=0
set ACT_LUT=0
vitis_hls -f scripts/run_resgru.tcl > results/csim_reference.log 2>&1
call C:\Project\venv_dpd\Scripts\activate.bat
python tools/verify_reference.py
```

검증 스크립트는 매번 현재 hw_ref.py로 참조를 다시 만들고 7680x2 형상을 확인한 뒤
compare_out.py와 eval_pa.py를 실행한다. 원시 결과는 results/v1.1_reference/csim_reference/에 저장.
기존 results/hls_out.txt는 C-sim을 재실행하면 덮어써진다.

v1.3 이후 기본 FEx는 16비트 중간값 후보로 변경되었다. 이 v1.2 실험 재현에는
반드시 FEX_INTERNAL_FIXED=0 및 ACT_LUT=0을 지정해 double FEx/활성화 기준을 재현한다.

다음은 정확도 여유를 유지하면서 double 활성화/FEx를 하드웨어 구현에 적합한 계산으로
대체하는 실험과, 합성 후 II 및 구현 비용 검증이다.

# v1.2: 후보 A — FEx 중간값과 역수 모두 16,3

측정일: 2026-10-16. v1.1에서 확보한 초기 reference에 FEx 중간값 양자화를 적용한 첫 설계 후보다.
Python 모사와 C-sim을 별도 버전으로 구분하지 않고 이 후보의 검증 과정으로 함께 기록한다.
기존 E03은 두 후보의 모사, E04는 두 후보의 C 검증을 뜻했다. 현재 v1.2는 후보 A의 모사와 C 검증을 함께 기록하며 원시 로그는 보존한다.

## 변경 내용

- 공통 데이터 `<16,3>`, 가중치 `<16,4>`, 주요 누산기 `<32,12>` 유지. 출력층 누산은 `<16,3>`.
- 64샘플 호출 사이에는 은닉 상태를 유지하고 2,560샘플 구간 시작에서만 초기화.
- FEx의 I², Q², 합, 진폭, 진폭제곱·세제곱 및 최종 특징값을 각 대입 위치에서 `<16,3>`으로 양자화.
- 역수 `1/진폭`도 `<16,3>`으로 저장. 진폭이 0이면 역수는 0.
- v1.1과의 차이는 FEx의 최종 출력뿐 아니라 중간값도 양자화한다는 점.

sqrt·역수·sigmoid/tanh 자체는 double 수학 함수로 계산한 뒤 지정 형식으로 저장한다.
따라서 부동소수점 연산을 제거한 회로나 모든 연산을 16비트로 수행하는 회로는 아니다.

## Python 모사 → C 구현 → 검증

| 검증 항목 | 결과 |
|---|---:|
| Python PA NMSE | −45.06 dB |
| Python PA EVM | −49.03 dB |
| Python PA ACPR L / R | −52.99 / −50.16 dBc |
| C-sim | 전체 7,680샘플, 오류 없이 완료 |
| C/Python 출력 비교 NMSE | −196.87 dB, PASS (상한 −60 dB) |
| C PA NMSE / EVM | −45.06 / −49.03 dB |
| C PA ACPR L / R | −52.99 / −50.16 dBc |

정확도 세 기준은 모두 통과했다. 합성 II·RTL·구현 PPA는 이 후보에서 별도로 측정하지 않았다.
파일상 최대 오차 5e-11은 텍스트 출력 정밀도 차이 수준이며 파일의 완전 일치를 뜻하지는 않는다.

## 판단

v1.1 reference의 NMSE −45.48 dB 대비 약 0.42 dB 열화됐다.
역수는 진폭이 작아지면 커지므로 범위 `[-4,4)`인 `<16,3>`이 제약이 될 수 있다.
다음 [v1.3 후보 B](v1.3_candidate_b.md)에서 역수의 정수부를 늘려 비교했다.

## 근거와 재현

- Python 출력: `results/fex_comparison/python/fixed16_invI3.txt`
- Python 평가: `results/fex_comparison/python/evaluation.txt`
- C 소스·출력·로그: `results/fex_comparison/csim/invI3/`
- 비교: `results/fex_comparison/csim/compare_invI3.txt`
- C 평가: `results/fex_comparison/csim/evaluation.txt`의 invI3 출력 행

결과 폴더 이름은 당시 모사/검증 단계의 명칭으로 유지한다. 후보 이름과 파일의 대응은 위 목록을 따른다.
Python 모사는 v1에서 `python tools/compare_fex_precision.py`로 두 후보를 함께 재현한다.
후보 A C-sim은 Vitis HLS 2024.1 Command Prompt에서 다음과 같이 실행한다.

```bat
set STEPS=csim
set NT=7680
set ACT_LUT=0
set FEX_INTERNAL_FIXED=1
set FEX_INV_I=3
vitis_hls -f scripts/run_resgru.tcl
```

현재 기본 활성화는 이후 LUT 후보이므로 `ACT_LUT=0`을 반드시 지정한다.

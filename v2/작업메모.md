# v2 작업 기록

공유 기록은 P&R 완료 시점에 따라 [v2.1](result/v2.1/README.md), [v2.2](result/v2.2/README.md), [v2.3](result/v2.3/README.md)으로 정리했다. 변경 이유 → 계산 조건 → 정확도 검증 → HLS 합성 → Vivado 구현 순서로 기록한다.

원본 sehyeon v1에서 별도 분기한 보간·recurrent 게이트 분리 후보는 [v2.4-S](result/v2.4-S/README.md)로 기록했다. v2.3의 직계 후속은 아니다. 정확도와 II=2를 충족했으나 P&R WNS=-2.524 ns로 15 ns는 미달이다.

전체 비교는 [v2 개요](README.md), 원본 보고서는 [결과 목록](result/README.md)을 참고한다.

후속 실험의 의사결정과 결과는 [v2.3 이후 실험 정리](v2.3_이후_실험정리.md)에 기록했다.

# v1 / v2 변경사항 요약

최종 재현 보관본: 2026-11-04. **무엇을 어디서 바꿨는지**를 먼저 읽는 문서다. 변경 이유·실험 결과는 [채택 변경 이력](v1기반_채택변경_이력.md), 논문의 해당 블록과 수정 근거는 [논문 아키텍처 대응](v1기반_변경과_논문아키텍처_대응.md)에 있다.

## 버전 구분

| 구분 | 시작 → 끝 | 이 문서의 범위 |
|---|---|---|
| **v1** | 제공 v0 → 원본 sehyeon v1 완성 | **1~8번**. 정확도 복구, 상태식 정리, 조합 LUT로 II=2 |
| **v2: 현재 채택 계보** | 완성된 sehyeon v1 → 현재 최종 구현 | **9~15번**. 보간·비트 축소부터 상태 포화 생략까지 |
| **v2.1~v2.3: 별도 계보** | hyeonseo v1.7 → v2.1 → v2.2 → v2.3 | [별도 변경 목록](#v2-other). 현재 최종본에 그대로 누적된 이력이 아님 |

여기서 v2는 **2주차 후속 작업 범위**를 뜻한다. `v2.4-S`로 보관한 버전은 **10번까지**이고, 현재 최종본은 **15번까지**다. 11~15번에 새 공개 버전 번호를 부여한 것은 아니다. 실험 폴더 이름이 `v1_...`로 시작해도 9번 이후는 이 문서에서 v2 작업에 넣는다.

```text
v0 → [1~8] sehyeon v1 → [9~10] v2.4-S → [11~15] 현재 최종

hyeonseo v1.7 → v2.1 → v2.2 → v2.3  (별도 계보)
```

## v1 변경사항 — v0에서 1~8번까지

각 변경명을 누르면 아래의 코드 위치·전후 차이로 이동한다. 번호는 기존 채택 이력과 동일하다.

| 번호 | 변경사항 | 이전 → 변경 후 |
|---|---|---|
| 1 | [은닉 상태 리셋 주기](../changes/코드변경.md#change-01) | 매 64샘플 블록 → 2,560샘플 구간 시작 |
| 2 | [기본 자료형 범위](../changes/코드변경.md#change-02) | data/weight 16,2 → 16,3 |
| 3 | [활성화 함수](../changes/코드변경.md#change-03) | hard 근사 → sigmoid/tanh 직접 LUT 4,096칸 |
| 4 | [FEx 역제곱근 형식](../changes/코드변경.md#change-04) | inverse 16,8 → 16,6 |
| 5 | [가중치 표현 범위](../changes/코드변경.md#change-05) | weight 16,3 → 16,4 |
| 6 | [HLS 스케줄 설정](../changes/코드변경.md#change-06) | uncertainty 1ns·DSP full reg false·II=2 요청 적용 |
| 7 | [상태 갱신식](../changes/코드변경.md#change-07) | `(1-z)*n+z*h_prev` → `n+z*(h_prev-n)` |
| 8 | [LUT 조회 구조](../changes/코드변경.md#change-08) | 기존 LUT 접근 → 전체 분할·0클록 조합 조회 |

당시 작업 흐름은 **1~4번: v0의 알려진 문제 대응**, **5~8번: 남은 정확도·II·타이밍 조건 조정**으로 나뉜다. 완성된 v1에는8번까지 포함된다.

**v1 완성 상태:** data16,3 / weight16,4 / accum18,3, 직접 LUT4,096칸, FEx NR4·inverse16,6, HLS II=2. 이 재현 보관본에는 최종 소스와 단계별 변경 부분을 수록했다.

## v2 변경사항 — 완성된 v1에서 9~15번까지

각 행은 바로 앞의 **채택된 단계**와 비교한다. 사이에 실행한 기각 후보의 코드는 이어받지 않았다.

| 번호 | 변경사항 | 이전 → 변경 후 |
|---|---|---|
| 9 | [보간과 비트 축소](../changes/코드변경.md#change-09) | 직접 LUT4,096칸 → 256구간 보간; data16,3→15,3, weight16,4→14,4 |
| 10 | [recurrent 곱셈의 게이트별 분리](../changes/코드변경.md#change-10) | 공통 MVM → r/z/n 구분. **여기까지가 v2.4-S** |
| 11 | [GRU 누산 폭 확대](../changes/코드변경.md#change-11) | 항마다18,3 누산 → 21,6 누산 후 최종18,3 변환 |
| 12 | [recurrent 곱셈의 항별 분리](../changes/코드변경.md#change-12) | 게이트별 → 게이트+입력 항별 |
| 13 | [n recurrent 곱셈의 행별 분리](../changes/코드변경.md#change-13) | n의 입력 항별 → 출력 행+입력 항별 |
| 14 | [상태 갱신용 z 표현](../changes/코드변경.md#change-14) | signed15,3 → unsigned12,0; 소수부12비트 유지 |
| 15 | [상태 결과의 최종 포화 생략](../changes/코드변경.md#change-15) | AP_RND·AP_SAT → 같은 형식의 AP_RND·AP_WRAP 후 비트 전달 |

**현재 최종:** [state_nosat 소스](../src/) · [채택 기록](../reports/결과요약.md). HLS II=2, P&R 15ns 제약에서 WNS +0.093ns. 표의 3번 직접 LUT와 2·5번 자료형은 9번에서 갱신됐다.

### v2.1~v2.3 — 별도 코드에서 진행한 변경

| 버전 | 비교 기준 | 변경사항 | 코드·전후 설명 |
|---|---|---|---|
| v2.1 | hyeonseo v1.7 | accum32,12→18,3, 상태식 정리, GRU 5항 adder tree | 버전 기록, config.h, gru_cell.h |
| v2.2 | v2.1 | sigmoid/tanh를 각각 512구간 보간으로 변경 | 버전 기록, activations.h |
| v2.3 | v2.2 | data15,3·weight14,4, 보간256구간, `W_hn_h+b_hn`을 곱셈 전에16,4로 변환 | 버전 기록, config.h, gru_cell.h |

현재 채택 계보는 sehyeon v1로 돌아와 9번부터 진행했다. 이 별도 계보의 adder tree·recurrent 중간16,4 변환·FEx sqrt/역수 구현을 현재 최종본에 누적하지 않았다.

## 코드에서 무엇이 바뀌었는지 보기

[코드 변경 부분 모음](../changes/코드변경.md)에 각 단계의 **파일·함수 위치, 비교 기준, 변경 전후**를 모았다. 10~15번은 원본 diff도 함께 제공한다. 예전 실험 폴더 전체가 없어도 이 문서와 최종 코드로 변경을 읽을 수 있다.
